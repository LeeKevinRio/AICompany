**不擬任何句子的情況**

- 旗標為 no：不渲染任何文字，也不得有圖例、說明或 tooltip（C-4；Decision 8）。
- 清單為空：清單區塊整段不顯示，包括標題，只留 N9-06 靜態句（C-3；C-N210-8）。
- 非 ok 分支：`kept_pending_entries` 為 None，不顯示清單區塊，也不顯示 N10-04（C-N210-5）。N10-04 只用於 ok 分支。

## 三、擬稿說明與選擇理由

1. **N10-01 只有三件事實，一句帶過兩件、一句帶帳冊。** 沒有方向，沒有「請」，沒有「建議」，沒有日期或時機。
2. **N10-02 推薦 A 版。**
   - unknown 的意義是「判不出來」，句子只說判不出來。
   - B 版加帳冊子句是事實，但 unknown 狀態下讀者容易把後半句讀成「這一列受影響」。是否加，由風控裁示。
3. **N10-03a 用「本次寫入時」限定清單。**
   - 清單是寫入當下的快照，寫鎖釋放後才 commit 的列不在內（R-a）。
   - 句子沒有「全部」「以下為所有」「共 N 筆」之類的完整性字樣。
   - 沒有任何「其他指令不受影響」的反面陳述。
4. **N10-03a 後半句與 N9-06 同詞同義，是刻意的。** 沿用「本次重算前計算的」，避免同一畫面出現兩種說法。「重算」在 ok 分支允許使用（RC-41 只管兩個拒寫分支）。入口名稱「重算部署資金（REBALANCE）」在這幾句裡用不到，所以沒有引用。
5. **N10-03b 照 C-5 原意寫「只會有一筆成交」。** 這句沒有說「會成交」，也沒有說是哪一張。若風控認為「只會有一筆」仍可能被讀成「一定有一筆」，可改為「至多一筆」，請風控裁示。
6. **N10-04 兩版都含「清單無法取得」。** 沒有「請稍後再試」「請重新整理」這類動作建議，也沒有指向其他畫面。

## 四、待風控留意的一個事實落差（採用 (iii-c) 時才會發生）

- N10-01 的第一件事實是「本列在 TOTAL_DEPLOY 最近一次重新設定之前**產生**」。
- 旗標依 (iii-a)（`td_flag_basis == "time_order"`）判定時，這句為真：評估讀 TD 在 created_at 之前，而 created_at 早於 set_at。
- 旗標依 (iii-c)（`td_flag_basis == "recorded"`）判定時，R-a 競態那一列是「評估讀到舊戳記，但 created_at 在 REBALANCE commit 之後取值」。這時 created_at 晚於 set_at，「之前產生」不為真；為真的是「股數依重新設定之前的值計算」。
- 若 CEO 採用 (iii-c)，請風控裁示是否改用下列備選句，作為 `td_flag_basis == "recorded"` 時的版本。
  - **N10-01C（備選，僅 (iii-c) 採用時）**：本列股數依 TOTAL_DEPLOY 最近一次重新設定之前的值計算。成交結算時，若所指的批次仍待進場，以本列股數計入帳冊。
  - 這一句仍只有事實，不含方向、建議、時機。
  - 若風控同意，後端旗標需另給欄位區分兩種句型，前端不得自行判斷。
- 未採用 (iii-c) 時，本節不適用，N10-01 照原稿。

## 五、紅線自查

- 沒有方向（調高、調低、較多、較少）。(iii-c) 的方向句不在本檔，若要擬須另送風控。
- 沒有建議、時機提示、安撫詞；沒有「請」。
- 沒有「未標示的列依現行 TOTAL_DEPLOY 計算」或任何等義說法；旗標為 no 時不擬任何句子。
- 清單為空時不擬任何句子；N10-03a 沒有「沒有」「無」「全部」等完整性或不在場字樣。
- 沿用既有用詞：「已產生、尚未結算的指令」（T-02）、「待進場」。入口名稱未引用；若日後需要，只能寫成「重算部署資金（REBALANCE）」。
- 沒有代號舉例，沒有金額佔位符。
