## 〇、起草前先講四件會影響字面的事

1. **第 5 條 violated 句的尾端是 Kelly 揭露，不是比率句。** `_check_kelly_fraction` 的 violated detail 是「…目前佔比 X 已達或超過該上限。{disclosures}」，`disclosures` 是 `KELLY_WIN_RATE_IS_NOT_PROBABILITY` 等長句（`app/api/kelly_wording.py:199-226`）。W-a2 若依 W2 的慣例寫「上述比率…」，在第 5 條會指到那段勝率揭露而不是比率。**因此 W-a2 一律不用「上述」，改以 `{name}所用的比率` 自帶指涉**（第 1、4 條同理沿用同一句，不分版）。
2. **D-5 分支（Kelly 允許權重 ≤ 0）不附 W-a2。** 風控裁定 (3) 明定 D-5 分支 status／detail 不變、只把 observed 改 None；該句不印比率、與持倉無關，加 W-a2 反而多出一句不相干的揭露。故 W-a2 只附在「允許權重 > 0 且比率 ≥ 上限」的 violated 句。
3. **D-a 只有「不點名條號」的那一句會涵蓋第 3 條。** D-P、D-d1、D-d2 都逐條點名（第 1、4、5 條／第 2 條），本來就沒有宣稱第 3 條；真正會與 W-b1 矛盾的只有 D-a「比率會因此偏高。」。所以 D-a3 只需取代 D-a，不必動 D-P／D-d1／D-d2 對第 3 條的處理。
4. **6-a 之後，D-d1／D-d2 的「低於上限的結果…」確實失去所指。** own>0 時第 1、4、5 條只會是 violated（附 W-a2）或 not_evaluable（附 W-a1），不再有 passed；該分句下文已提出刪除版與改寫版。

**避開的否決理由**：不用「缺少輸入」（對 ETF／淨值過期不精確，W1 已列）；不以一個缺口的成因描述另一個缺口（2026-08-09 句 1，AC-12.3）；不用「未實際檢查」這類偏軟字眼；不含「通過」（W1-C 的前車之鑑改以「因此…不計算」表達）；不安撫、不給行動指示、不承諾恢復計算。

## 三、W-b1：第 3 條 violated，附在前句之後、`_net_worth_disclosure` 之前（進推播）

**變體條件**：`book_fully_valued is not True`、淨值新鮮、`A/N` ≥ 上限（violated 才附；未達上限維持 `GROSS_EXPOSURE_INCOMPLETE_BOOK_DETAIL` 與三句揭露，逐字不變）。組成順序：既有 violated 前句「組合總曝險 X（已估值部位市值合計 ÷ 自報帳戶總淨值），已達或超過上限 Y。」→ W-b1 → `_net_worth_disclosure`（三句，可含老化提示）。不進 `notional_caps`。

**推薦 W-b1（C，43 字）**

> 帳本內有部位無法估值；計入無法估值的部位後，比率不會低於上述數字，但實際比率無法確認。

渲染例（推播）：「2330 觸發風險上限：總曝險上限。組合總曝險 160.0%（已估值部位市值合計 ÷ 自報帳戶總淨值），已達或超過上限 150.0%。帳本內有部位無法估值；計入無法估值的部位後，比率不會低於上述數字，但實際比率無法確認。分子（已估值部位市值合計）由系統計算，分母（帳戶總淨值）由使用者自報，兩者來源不同。…」

**備選 W-b1-A（把機制說出來，44 字）**

> 帳本內有部位無法估值；若將這些部位也計入分子，比率不會低於上述數字，但實際比率無法確認。

**推薦 C**：C 的主句就是風控裁定 (2) 允許的範圍用語（「計入無法估值的部位後，比率不會低於上述數字」），限定語完整保留，核可摩擦最小。A 多說了「計入分子」，機制更清楚（分母是自報淨值，不隨估值變動，所以只有分子增加），但「這些部位」要靠前一分句指涉；字數相當，若風控偏好把單調性機制寫明，改用 A。

**為什麼這樣寫（對應風控 (2)）**
- 方向宣稱**限定**為條件句：「計入無法估值的部位後」是限定語，不省略；結論用「不會低於」（含等於，因為未估值部位的真實市值可能接近 0，風控已據此否決「只會更高」），不用「更高」。
- 補「但實際比率無法確認」：宣稱的只是比率的下界方向，不宣稱真值；也避開「實際曝險」一詞（風控指出實際曝險還受自報淨值與收盤價時效影響）。
- 「上述數字」緊接在 violated 前句之後，指涉唯一（前句只有一個比率）；W2 審查已接受「上述」指緊鄰前句。
- 不含任何操作指示（不寫賣出、降低曝險、補填、更新）。
- 與後接的三句揭露不衝突：第 2 句「未登錄的部位不計入分子，會讓曝險看起來偏低」講的是**未登錄**的部位，W-b1 講的是**已登錄但無法估值**的部位，兩者並陳不重複。
- 用「帳本內有部位」（比照 W3 起頭，不用「另有」）；不帶筆數。

**避開的否決理由**：「實際曝險只會更高」（逐字否決）；省略限定語；操作指示；把「不會低於」寫成「更高」。

**禁詞自查**：C、A 皆 0 命中。

> 第 1、2、4、5 條上限的比率會因此偏高；第 3 條上限（總曝險上限）不在此列，其比率因無法估值的部位未計入分子而可能偏低。

組成渲染例（live，決策卡）：「組合中有 2 筆部位無法估值（缺價格或匯率），未計入總資產；第 1、2、4、5 條上限的比率會因此偏高；第 3 條上限（總曝險上限）不在此列，其比率因無法估值的部位未計入分子而可能偏低。」cache_only 版同理接在原括號成因之後，成因句一字不動。

**`{target}` 參數的處理（需風控確認）**：任務要求兩範圍以 `{target}` 區分、不複製。逐項檢查後，D-a 的觸發條件（決策卡 a／a0／無重疊；`/limits` e／f）之下，第 1、2、4、5 條在兩個範圍都是「偏高成立」，第 3 條在兩個範圍都經同一個 `_book_level_check`／`_check_gross_exposure` 產出同一句 W-b1，**我找不到會讓字面分叉的事實**，所以 D-a3 兩範圍**同一句、同一常數**，不需要 `{target}`；「不複製」的目標由單一常數達成。條號名稱「總曝險上限」建議由 `LIMIT_NAMES["gross_exposure"]` 組字串。若風控判斷兩範圍需要分叉，提出具體差異後我再補 `{target}` 版本，不影響其餘字面。
- 風控若要求第 1、2、4、5 條補全名（D-P 的「補全名」為 suggested），長版約 103 字：「第 1、2、4、5 條上限（單一標的佔比上限、單一產業佔比上限、單筆最大可承受虧損、分數 Kelly 部位上限）的比率會因此偏高；…」。我推薦短版：這一句要排除的只有第 3 條，所以只有第 3 條補全名。

**為什麼這樣寫**
- 明確把第 3 條排除在「偏高」之外，並說出相反方向「可能偏低」，與 W-b1「計入後不會低於上述數字」一致（「可能偏低」是對「不會低於」較弱的同向說法；D-a3 不重複下界宣稱，下界宣稱只留在第 3 條自己的 detail）。
- 成因寫「因無法估值的部位未計入分子」，與 W-b1、`GROSS_EXPOSURE_INCOMPLETE_BOOK_DETAIL` 同詞「分子」；live 與 cache_only 兩種成因都成立（只說「無法估值」）。
- 前半「第 1、2、4、5 條上限的比率會因此偏高」是 D-a 原意的列舉化，不新增任何方向主張。

**待實作端確認（非字面）**：選 D-a3 需要在組 notes 時就知道第 3 條是否 violated（`book.py` 的 `_book_level_notes` 目前不看上限判定）。這會讓 notes 組裝依賴 `limits` 判定結果，請 tech-architect 在 ADR-0023 寫明資料流；若要避免耦合，次選是「淨值存在且新鮮、帳本不完整」即選 D-a3（第 3 條 not_evaluable 時 D-a3 的「其比率…可能偏低」變成描述一個未計算的比率，字面仍不為假但會偏冗），但這與風控裁定「D-a 原句只在第 3 條 not_evaluable 時使用」不一致，需風控改裁才可採用。

**避開的否決理由**：D-a 涵蓋偏低的第 3 條（風控失效條件 1）；省略限定語；對第 3 條宣稱方向定論（只說「可能偏低」）。

**禁詞自查**：D-a3 0 命中。

## 五、6-a 落地後 own>0 時的方向子句處置（D-d1／D-d2；required，6-a 同一包）

**問題**：D-d1／D-d2 現行核可字面結尾「其低於上限的結果也可能建立在偏低的比率上」（d1）與「低於上限的結果也可能建立在偏低的比率上」（d2）所指的是第 1、4、5 條的 passed。6-a 落地後 own>0 時這三條只會是 violated（附 W-a2）或 not_evaluable（附 W-a1），不再有 passed，該分句失去所指（風控失效條件 2）。own=0 時優先序 1 不成立，不會選到 D-d1／D-d2，所以這個問題只存在於 own>0。

**推薦：刪除該分句**（刪除版）。

| | 現行核可字面（風控 2026-10-07 D-d1 更正；D-d2 原表） | 刪除版（推薦） |
|---|---|---|
| D-d1 | 因本標的自身的持倉無法估值，第 1、4、5 條上限（單一標的佔比上限、單筆最大可承受虧損、分數 Kelly 部位上限）的比率會偏低，其低於上限的結果也可能建立在偏低的比率上。（87 字） | 因本標的自身的持倉無法估值，第 1、4、5 條上限（單一標的佔比上限、單筆最大可承受虧損、分數 Kelly 部位上限）的比率會偏低。（66 字） |
| D-d2 | 因本標的自身與其他標的的持倉皆無法估值，第 1、4、5 條上限（單一標的佔比上限、單筆最大可承受虧損、分數 Kelly 部位上限）的比率方向不定，可能偏高也可能偏低，低於上限的結果也可能建立在偏低的比率上。（103 字） | 因本標的自身與其他標的的持倉皆無法估值，第 1、4、5 條上限（單一標的佔比上限、單筆最大可承受虧損、分數 Kelly 部位上限）的比率方向不定，可能偏高也可能偏低。（83 字） |

**推薦刪除的理由**
- 刪的是「已無所指」的後果分句；保留的前半仍為真：d1 在 own>0 且其餘三類為 0 時，三條比率確定偏低（風控已核可的更正）；d2 方向不定。
- 與 W-a1／W-a2 不衝突：W-a1「可能偏低」、W-a2「實際比率無法確認」是逐條 detail 的保守寫法，D-d1 的「會偏低」是 note 層在 d1 條件下才選用的較強主張，兩者方向一致、強度不同。注意 D-d1 的「會偏低」在 violated 時等於告訴讀者那個被印出的比率是下限，這在 d1 數學上成立，也是 D-d1 只在 d1 選用的原因。
- 「低於上限的結果」的功能（提醒 passed 不可靠）已由 6-a 的判定本身取代：不再有 passed，也就沒有需要提醒的 passed。
- 刪除版比改寫版少一組「系統行為」陳述，不與 D-5 分支或其他原因造成的 not_evaluable 產生例外。

**備選改寫版（R，不推薦）**：把已失效的分句改為說明結果，d1 94 字、d2 111 字。

- D-d1-R：…的比率會偏低，因此未達上限時這三條不計算，已達上限時仍以已達上限處理。
- D-d2-R：…的比率方向不定，可能偏高也可能偏低，因此未達上限時這三條不計算，已達上限時仍以已達上限處理。

R 的好處是讀者在 note 就知道為什麼三條各是什麼狀態；缺點：(1) 與逐條的 W-a1／W-a2 重複；(2) 「未達上限時這三條不計算」有例外：第 5 條 D-5 分支永遠 violated 且與比率無關、第 4 條可能因缺 ATR 而 not_evaluable，note 的一般性陳述要為這些例外負責；(3) 把系統行為寫進 note，日後 6-a 判定規則（例如列管中的「own>0 且 add 降級」）調整時，note 要跟著改。

**連動**：D-d1／D-d2 的優先序（own>0 → 先於 X 為 None 與 D-P）、`LIMIT_NAMES` 組字串、「d 且 X 為 None 時第 2 條維持 `NO_SECTOR_DETAILS[gap]`」等既有 required 一概不變；本處置只動兩句的結尾。

**禁詞自查**：刪除版與改寫版皆 0 命中。

## 六、`SECTOR_UNCLASSIFIED_NOTE` 中性句（low；僅供另案送審，不得併入本包實作）

**現行句（`book.py:144-148`，2026-08-09 風控核可，FR-12 句 2 修正句，`work/reviews/c1-phase8-review.md`；84 字）**

> 組合中有 {count} 筆已估值持倉未填產業別，合計市值新台幣 {amount:,.0f} 元、佔總資產 {share}，未計入任何產業的市值合計；單一產業佔比可能被低估，這條上限的通過判定也可能建立在偏低的比率上。

**現行句的兩個問題**
1. 「未填產業別」對 ETF 與非台股不成立且暗示使用者遺漏：ETF 的產業別分類不適用（D6）、非台股尚無分類方式（D8），使用者沒有遺漏任何東西；風控 6-c 裁定已列管（low）。
2. 句末含「通過」二字，在本次任務單列的禁詞內（原句 2026-08-09 核可時的禁詞範圍較窄）；改寫時一併改成 W3 家族的「低於上限的結果」。

**推薦中性句（N1，96 字）**

> 組合中有 {count} 筆已估值持倉沒有產業分類，合計市值新台幣 {amount:,.0f} 元、佔總資產 {share}，未計入任何產業的市值合計；單一產業佔比可能被低估，若單一產業佔比上限顯示低於上限，該結果也可能建立在偏低的佔比上。

**備選 N2（97 字）**：「沒有產業分類」換成「未歸入任何產業」。與後文「未計入任何產業」重複「任何產業」，讀起來較繞，不推薦。

**為什麼這樣寫**
- 「沒有產業分類」描述**狀態**而非成因：台股未填（欄位空白）、ETF（分類不適用於基金）、非台股（尚無分類）三子類都為真，不指名任何一種成因（2026-08-09 句 1 VETO 核心、股數區間文案裁決 ⑥⑦⑧「彙總句不得指名單一成因」），也不暗示使用者遺漏。
- 不寫「不屬於任何產業」：風控裁定 5 與 6-c 已把 ETF／非台股列為「可能屬於」，「不屬於」會與之矛盾。
- 沒有任何「請填」或補救指引（D6、D8 先例：對 ETF／非台股承諾做不到的事）。
- 保留 2026-08-09 句 2 的要求：筆數＋市值＋佔總資產三者並陳（筆數會掩蓋大小），一字不刪。
- 結尾沿用 W3 家族的「低於上限的結果也可能建立在偏低的佔比上」，並寫成條件句（「若…顯示低於上限」），因為本 note 與第 2 條 detail 是分開的兩處，不能用「上述」指涉；用全名「單一產業佔比上限」取代原句的「這條上限」，避免在 notes 清單中指涉不明（建議由 `LIMIT_NAMES["sector_weight"]` 組字串，與 D-d1／D-d2 同規）。
- 「單一產業佔比可能被低估」維持原句（對三子類皆成立：未計入任何產業的已估值市值只會讓某產業的佔比偏低或持平）。

**避開的否決理由**：用一個缺口的成因描述另一個缺口；「未實際檢查」；「請填產業」；「通過」；斷言「屬於」。

**禁詞自查**：N1、N2 皆 0 命中。**審查路徑**：現行核可句在新句核可前照舊；改動須重新送審並於常數註解寫明新核可日期與審查檔。附帶提醒：6-c 採 C-1 後，帶這則 note 的情境第 2 條幾乎永不參與試算，與本句「結果也可能建立在偏低的佔比上」不衝突。
