# C8 修復回歸對照——win_rate / profit_factor 統計單位由 fill 層改回合層

- **案由**:C8(CEO 2026-08-19 裁決立案,P1)。每日再平衡使滿倉期間逐日產生微額結算 fill,`report._trade_stats` 把每筆 fill 當獨立交易計入勝率與獲利因子(quant D-9 意見 §2.1 實測污染)。
- **修法**:依架構收斂裁決 4(b),report 層修=bug fix 不需 ADR。`win_rate` / `profit_factor` 統計單位改為**完整回合(round trip)**,回合抽取與歸屬**唯一**由 `app/backtest/episodes.py` 供給(約束 28 精神,report.py 不重寫第二份回合邏輯);`num_closing_trades` 保留原「結算筆數」語意不動;`round_trip_win_rate` / `round_trip_payoff_ratio` 欄位維持(C5 顯示層契約不變),修復後 `win_rate` 與 `round_trip_win_rate` 同源同值,以測試釘住。
- **產出工具**:`apps/stock-desk/backend/scripts/c8_regression_comparison.py`(`uv run python scripts/c8_regression_comparison.py`),舊值=修復前 `_trade_stats` 原邏輯逐字重現;新值=修復後報表實際輸出;隨機漫步樣本比照既有測試慣例(`tests/test_api_kelly_import.py` 的 `random.Random(seed).gauss` walk)。

## 差異解讀

1. **樣本膨脹確證**:closing fill 數為回合數的 6.8~7.3 倍(如 breakout full:684 fills vs 100 回合),即 D9 §2.1 描述的微額 fill 稀釋效應。
2. **D9 的 21pp 級距重現且更大**:`rsi_reversal` 的 fill 層 vs 回合層勝率差達 **+32.5~+33.7pp**(D9 在 30,000 根合成日線上的漸近估計為 21pp),方向一致(fill 層低估 rsi_reversal 的 p、高估其 b);`breakout` 方向相反(fill 層高估 p 達 13.8pp)。污染方向依策略而異,不能事後校正,只能改統計單位。
3. **PF 在 full 區段幾乎不動**(2.491→2.492 等):與 D9 一致——PF 取總和,微額項相抵;但 **OOS 區段 PF 會動**(ma_cross oos 1.109→1.023),因回合層採「完全包含歸屬」,跨界回合的損益不再被日期過濾的 fill 切片誤計入。
4. **衍生風控量級**:以 kelly_fraction(p, b) 換算,rsi_reversal 額度差約 2 倍、breakout 由「舊數字判無優勢(f\*<0)」翻為正——差異超過 D9 宣稱的 50%,同屬「fill 層 p/b 不是 Kelly 所需量的估計量」的證據。
5. **方向摘要**:修復後數字不是一律變好或變壞——ma_cross 幾乎不動、rsi_reversal 大幅走高、breakout 走低。舊值的偏差由「微額 fill 的正負號雜訊 + 樣本單位錯置」決定,與策略優劣無關。
