# 進場觀察條件面板 — PRD（2026-09-06）

> CEO 需求：「還有進場點的觀察」→ 提案六條固定觀察條件清單，CEO 回覆「可以 你直接做」。
> 產品線：stock-desk 個股頁 `/position/[symbol]`。product-manager 出稿。

## 1. 問題

頁面已回答「現價在區間哪裡」「進場後停損停利在哪」，但沒有回答「**現在符合幾個進場前該看的條件**」。CEO 要一個一眼看懂的條件清單，依常見教科書標準，不是統計、不是指令。

## 2. 範圍

- 新面板「進場觀察條件」（名稱由 creative-lead 起草、風控定案），位置：操作摘要與資料來源指引句之後、關鍵價位參考之前。
- 六條固定條件，每條三態：**成立／未成立／無法判定**；面板頂部顯示「6 條中成立 N 條」與六格點狀刻度（●○—）。
- 資料全部來自頁面既有查詢（bars→KeyLevels、signals、advice、positions），不新增後端。
- 價位階梯：把「拉回觀察區（MA20 ±3%）」內的價位列加淺色標記與標籤，讓現價與觀察區的距離一眼可見。
- 頁尾揭露區新增一組（組名＝面板標題）：六條門檻的計算依據與限制句；面板原位留一句指引句（沿用 `buildFooterGuidance`）。
- 面板內常駐一句限定語（不下沉；新面板不在 2026-09-06 兩次下沉裁定範圍）：條件為本面板自訂之固定門檻，成立數不代表機率、勝率或任何買賣判斷。

## 3. 六條條件（門檻為本面板自訂教科書值）

| # | 名稱 | 成立條件 | 資料 | 無法判定時 |
|---|---|---|---|---|
| 1 | 位階 | 近 N 根區間位階 ≤ 70% | KeyLevels.rangePositionPct | 位階 null（< 60 根或區間為零） |
| 2 | 趨勢 | 收盤 > MA60 | KeyLevels.close／ma60 | ma60 null |
| 3 | 拉回 | \|收盤／MA20 − 1\| ≤ 3% | KeyLevels.close／ma20 | ma20 null |
| 4 | 動能 | RSI 在 30–70 之間（不含端點；同速覽「中區帶」） | signals.technical.rsi.last.rsi | RSI 不足 |
| 5 | 量能 | 成交量 z 在 −2 與 2 之間（不含端點） | signals.technical.volume_zscore.last.zscore | 不足 |
| 6 | 規則 | 建議引擎本次未命中任何防禦型方向規則 | advice.matched_rules × direction_weights | advice 不可用／insufficient_data |

- 觀察值一律以數字顯示在條件旁（位階 %、收盤 vs MA60、距 MA20 %、RSI、z、命中防禦型規則數）。
- 六條皆無法判定時，面板顯示無資料狀態句，不顯示計數。

## 4. 驗收條件（Given／When／Then）

- AC-1 Given 2330 demo 持倉（位階 71%、收盤 > MA60、距 MA20 −0.5%、RSI 51、z 0.7、命中一條防禦型），When 開啟頁面，Then 顯示「6 條中成立 4 條」，位階與規則兩條為未成立，各條觀察值與截圖一致。
- AC-2 Given 日線 < 60 根，Then 位階條為「無法判定」且計數分母仍為 6、標示無法判定條數。
- AC-3 Given advice 回 insufficient_data，Then 規則條為「無法判定」，其餘五條照常。
- AC-4 面板任何字面不含 FRONTEND_FORBIDDEN_TERMS；不出現「可以進場」「時機」「買點」「勝率」等；成立數不得換算成分數、百分比或等級。
- AC-5 成立／未成立的顏色不用紅綠；成立用 sky、未成立用 neutral、無法判定用「—」。
- AC-6 階梯內位於 MA20 ±3% 的列有「觀察區」標籤與底色；MA20 為 null 時不標。
- AC-7 頁尾新增組，六條門檻逐條揭露；面板原位有指引句；`componentWordingScan` 釘住全部字面並掃描禁用詞。
- AC-8 typecheck、vitest 全綠；桌機與 390px 無橫向溢出。

## 4b. 風控預審（2026-09-06）：VETO → 依 R-01～R-22 修訂後進 build

- **RED-1 → 採路徑 (a)**：未持有（advice `held=false`）或持有狀態未定時，第 6 條一律「無法判定」，不得判為成立。
- **RED-2 → 採路徑 B**：標題不含「進場」；狀態詞維持成立／未成立／無法判定；全頁字面禁「進場點」「時機」「時點」「買點」「訊號」「條件成立」「達標」「過關」。
- **R-11**：條件以資料項命名並與門檻並置：位階（≤70%）／收盤與 MA60／距 MA20（±3%）／RSI(14)（30–70）／成交量 z（−2～2）／防禦型規則命中數（=0）。
- **R-12／R-18**：MA20 ±3% 價位帶不得稱「拉回觀察區」；階梯標籤直接印門檻「MA20 ±3%」。
- **R-04～R-10**：六條逐條可見、併印觀察值、順序寫死；計數只用「6 條中 … N 條，其中 M 條無法判定」句型，禁 N/6、百分比、分數、等級、進度條；全部成立無任何特殊態；六格點狀刻度 1:1 同序同尺寸；計數字級 ≤ text-lg；不得離開個股頁、不得存時間序列或跨標的比較；禁倒數／逼近語。
- **R-13**：收盤與 MA60 同取自 KeyLevels（單一 bars payload）；`indicatorBands.ts` 不得復活 `closeVsMa`。
- **R-14**：位階條印出實際根數；頁尾組重述「位階高低不代表估值高低」。
- **R-15／R-17（E-2）**：面板內常駐交叉引用句：本面板不是操作摘要結論的一部分，結論、信心等級與免責見上方操作摘要；面板不得 import／渲染 headline、action label、信心等級、disclaimer。
- **E-1～E-4 留原位**（不適用兩次下沉裁定；≥ text-sm／≥ neutral-400、不摺疊）：E-1 門檻自訂＋成立數只是條數＋否定式列舉（機率、達成率、買賣判斷）；E-2 交叉引用；E-3「—」＝無法判定，不是零也不是未成立；E-4 三份查詢的資料時間。
- **R-21**：成立／未成立／無法判定一律 neutral 單色，以形狀（●○—）＋文字＋aria 三重編碼；狀態常數區塊禁任何色相。
- **R-19**：位置固定為 操作摘要 → 資料來源指引句 → 本面板 → 關鍵價位參考。
