# PRD：manjong-unity（台灣 16 張麻將遊戲）v0.1 可玩原型

- 產品線分支：`product/manjong-unity`
- 程式位置：`apps/manjong-unity/server`（TypeScript 後端）、`apps/manjong-unity/client`（Unity 6.3 LTS 用戶端）
- 規則細節：[`規則與台數表.md`](規則與台數表.md)
- 架構決策：[`adr/M001-架構與前後端切分.md`](adr/M001-架構與前後端切分.md)
- API 契約：[`api-contract.md`](api-contract.md)

## 1. 目標

做出一款可在瀏覽器（Unity WebGL）上玩的**台灣 16 張麻將**：玩家一人對三個 AI，
採台灣常用台數表（含嚦咕嚦咕、八仙過海、七搶一等），用假金幣結算，並有排行榜。

## 2. CEO 已拍板的範圍（2026-10-03）

| 項目 | 決定 |
| --- | --- |
| 規則 | 台灣 16 張，台灣常用台數表「全開」（含嚦咕嚦咕） |
| 模式 | 先做單機：1 位玩家 vs 3 個 AI |
| 平台 | WebGL 優先 |
| 金流 | 只有假金幣（虛擬資產，不可儲值、不可兌換）；儲值不做 |
| 排行榜 | 要做（以金幣排序） |
| 美術 | 2D、可愛風 |
| AI | 先能打，難度分級留到下一版 |
| 帳號 | 只做訪客登入，其他登入方式之後再做 |
| 引擎 | Unity 6.3 LTS；後端 TypeScript |

## 3. 不在本版範圍

線上多人、儲值、第三方登入、AI 難度分級、正式美術與音效、手機版排版最佳化、正式部署。

## 4. 沿用的既有 CEO 決定

延續 MahjongScore（`apps/web`）已拍板的計分慣例：**底 100 / 每台 50**、**做莊 1 台、連 N 拉 N = 2N 台、
只在牽涉莊家的支付加台**。

## 5. 驗收條件（Given / When / Then）

### 帳號
- **AC-1** Given 第一次開啟遊戲，When 進入大廳，Then 自動建立訪客帳號（暱稱「訪客xxxx」、初始金幣 20,000），重新整理後仍是同一個帳號。
- **AC-2** Given 在大廳，When 輸入 1–12 字的新暱稱並送出，Then 暱稱更新且排行榜顯示新暱稱；空白或超長暱稱被拒絕並顯示原因。

### 牌局
- **AC-3** Given 在大廳按「開始遊戲」，When 牌局開始，Then 擲出莊家、每家 16 張（莊家 17 張）、花牌自動補花，並顯示圈風、莊家、剩餘張數。
- **AC-4** Given 輪到我，When 我點一張手牌再點一次確認，Then 打出該張；AI 依序摸打，每一步都看得到。
- **AC-5** Given 別家打出我可吃 / 碰 / 槓 / 胡的牌，When 系統詢問，Then 出現對應按鈕與「過」；只能吃上家的牌。
- **AC-6** Given 我摸牌後可自摸、暗槓或加槓，When 系統詢問，Then 出現對應按鈕；加槓時其他家可搶槓胡。
- **AC-7** Given 有人胡牌，When 該局結束，Then 顯示胡牌者、放槍者（或自摸）、所有台數名目與總台數、每家金幣增減、攤開四家手牌。
- **AC-8** Given 牌牆只剩保留牌（16 張），When 下一家需要摸牌，Then 流局且莊家連莊。
- **AC-9** Given 一圈（東風圈）打完，When 最後一局結束，Then 顯示整場結算並回到大廳。

### 規則正確性（以自動化測試驗收）
- **AC-10** Given 規則文件中的每一個台數名目，When 跑後端測試，Then 每個名目至少有一個正例測試，互斥規則（如門清自摸取代門清＋自摸）有測試。
- **AC-11** Given 1,000 局 AI 對打模擬，When 跑完，Then 無例外、每局 144 張牌守恆、每局金幣四家加總為 0。

### 金幣與排行榜
- **AC-12** Given 每局結束，When 結算完成，Then 我的金幣持久化（伺服器端），AI 金幣只在本場顯示。
- **AC-13a** Given 一局結算時我該付的金額超過剩餘金幣，When 結算，Then 我最多付到 0，贏家只收實際付出的金額；金幣為 0 時整場立即結束，無法打下一局。
- **AC-13** Given 我的金幣低於 1,000，When 在大廳按「領救濟金」，Then 金幣補到 10,000；金幣不低於 1,000 時不可領。金幣不足 1,000 時不能開局。
- **AC-14** Given 在大廳，When 開啟排行榜，Then 依金幣由高到低列出前 50 名（暱稱、金幣、胡牌次數、最大台數），並標示自己。

### 安全
- **AC-15** 所有規則判定、洗牌、AI 決策與結算都在伺服器端；用戶端只送「選了哪個合法動作」，伺服器驗證動作合法性，非法動作回 400。
- **AC-16** 用戶端看不到其他家手牌與牌牆（局中 API 回應不含這些資料）。
