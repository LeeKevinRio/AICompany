## 0. 設計原則與資料前提

1. 一眼看到：已查到最低價、哪家航空、哪一班、幾點出發抵達、去哪看並訂。次要資料預設收合。
2. 一張卡一個重點：價格最大，航班次之，其餘 muted。
3. 不裝飾：無插圖、無航空 logo、無圖示字型。只用文字與 Unicode 符號（→ ↓ ↑ ▸ ▾ ↗）、純 CSS。
4. 中性呈現：主卡與列表卡片只靠尺寸與位置突出最低價，不加「推薦」「最佳」性質的視覺標記（見第 4 節）。
5. 狀態不只靠顏色：每個徽章與漲跌都有文字或符號。

### 資料前提（本批目標為完整版）

總經理已用 fixture 實測：航班號碼、抵達時刻、抵達日偏移（+N／−N）、轉機點，payload 皆可取得（T1 解析逐段明細）。**完整版為本批目標**；舊資料（新欄位 NULL）才顯示「—」。

規則：

- 完整版：航空公司、航班號碼、出發與抵達時刻（含 +N／−N）、直飛或轉機（含轉機點）、飛行時間，全部呈現。
- 舊資料或解析降級（欄位 NULL）：該欄**原位顯示「—」**，不整段省略、不錯位（對應任務單必過項）。範例見 2.3 末。
- 禁止捏造或推算航班號碼、抵達時刻、偏移天數；出發時刻加飛行時間不能推算抵達時刻（跨時區）。
- 只列**去程**航班。頁面任何位置不得出現回程航班，也不得暗示已知回程（任務單範圍外；風控 R10）。
- 線框內所有數字（價格、時刻、航班）均為版面示意，**非真實資料**，上線不得照抄。

### 2.3 航班資訊列 `.flight`

用於：卡片、主卡、表格儲存格、比價結果。同一結構，三種尺寸。**只呈現去程單組**。

結構：

```
行 0（僅來回）:  去程
行 1:  {航空公司}  {航班號碼}
行 2:  {出發時刻} {出發機場} → {抵達時刻} {抵達機場} {+N|−N}
行 3:  {直飛|轉機 N 次（轉機點）}・{飛行時間}
```

「去程」標籤只在來回時顯示（`--text-sm`、600、muted，置於行 1 前方同一行）；單程不加。卡片與表格儲存格行 2、行 3 可併為一行（放不下才換行）。

規格：

| 元素 | 樣式 |
|---|---|
| 航空公司 | `--text-base`（主卡 `--text-lg`）、600、`--color-text`；多航空以「、」連接（例：`長榮航空、日本航空`），不截斷 |
| 航班號碼 | mono、`--text-sm`、`--color-muted`；與航空公司間距 `--space-2`；多段以「 → 」連接（例：`BR 189 → JL 99`） |
| 出發／抵達時刻 | `--text-lg`、600、tabular-nums、24 小時制 `HH:MM` |
| 機場代碼 | `--text-sm`、`--color-muted`，接在時刻之後 |

### 2.5 收合區塊 `<details class="fold">` 與可展開說明

**A. 區塊收合 `details.fold`**（包次要表格、監看條件、設定資料）

- `<summary>`：flex、左右對齊；左為標題（`--text-base`、600）＋筆數（muted；**筆數必須是實際資料筆數**）；右為「展開」「收合」提示（muted `--text-sm`）。
- 最小高度 44px（手機 48px），padding `--space-2` × `--space-4`，底 `--color-surface`，邊框 1px `--color-border`，圓角 `--radius`。
- 標示：`summary::before` 用文字符號 `▸`（收合）、`▾`（展開，`details[open] > summary::before`），無旋轉動畫。隱藏預設三角：`list-style: none` 與 `::-webkit-details-marker { display: none }`。
- `:hover`：底改 `--color-bg`（120ms 過渡）。`:focus-visible`：沿用全域 2px `--color-focus` outline。
- 展開內容：上方 `--space-3`，內容不再包第二層卡片邊框。
- 既有 `.table-wrap` 的橫向捲動規則保留。
- 收合區內展開後出現的價格，仍須各自帶可見查到時間與（多人時）人數總價；收合區的 summary 不可含價格數字。

## 3. 對比度（WCAG AA）

方法：依 WCAG 2.x 相對亮度公式逐色手算，數值為估算（誤差約 ±0.1）。門檻：一般文字 ≥ 4.5:1、非文字元件（focus、邊框）≥ 3:1。價格 28px／36px 雖屬大字，仍採 4.5:1。實作後請 qa-e2e 用腳本重算，若與此表差 > 0.3 以實測為準。

| 前景 → 背景 | 用途 | 淺色 | 深色 |
|---|---|---|---|
| text → surface | 內文、價格、主卡全部文字 | 16.5 | 13.2 |
| text → bg | 頁面內文 | 15.4 | 14.6 |
| muted → surface | 查到時間、航號、說明 | 5.7 | 6.6 |
| muted → bg | 頁面次要文字 | 5.3 | 7.3 |
| accent → surface | 連結、hover 邊框、summary 連結 | 6.1 | 6.1 |
| accent-text → accent | 主按鈕（CTA） | 6.1 | 7.0 |
| accent-text → accent（hover，brightness 1.08） | CTA hover | 5.4 | 約 7（不降） |
| ok-text → ok-bg | 「啟用」、降價標籤 | 6.8 | 7.9 |
| warn-text → warn-bg | 需人工查價、可能已過期、近 N 輪未更新 | 6.7 | 8.6 |
| warn-text → surface | +N／−N | 7.4 | 10.8 |
| bad-text → bad-bg | 漲價標籤 | 7.5 | 7.6 |
| neutral-text → neutral-bg | 「停用」「已結束」、持平 | 7.7 | 8.0 |
| danger → surface | 刪除、錯誤 | 6.5 | 6.3 |
| input-border → surface（非文字，需 ≥ 3） | 控制項邊框 | 4.2 | 約 4（沿用，未改動） |
| focus（accent）→ surface（非文字，需 ≥ 3） | focus ring | 6.1 | 6.1 |

附註：

- v2 不再使用 `--color-best-bg`，相關三組對比已移除。
- `--color-border`（#dcdfe4）對白底約 1.3:1，僅作裝飾分隔，不承載資訊；卡片邊界另靠留白。
- 所有文字背景組合均使用既有 token，無新色，故無需補驗新組合。

## 4. 禁止事項

- 裝飾性插圖、航空 logo、機票圖示、背景圖、漸層。
- 外部資源：外部字型、CDN、外部圖片、`data:` URI 圖片；外部連結只指向 Google Flights。
- 動畫：唯一允許 hover 的 `background-color`／`border-color` 120ms 過渡；`prefers-reduced-motion: reduce` 時關閉（把 `.watch-card`、`.fold > summary` 加進既有 reduced-motion 規則）。禁止展開動畫、載入骨架動畫、旋轉、淡入、價格跳動。
- inline style（含 `style=` 屬性）。
- **推薦式強調標記**：主卡與列表卡片不得有「最便宜」「推薦」「最佳」「超值」等字樣、星號／皇冠／緞帶／火焰等符號、accent 色邊框或底色填充、比其他卡更重的陰影；下跌標籤不得比上漲標籤更醒目。違反或要加強調需重新送審。
- **回程航班**：不得顯示回程航班資訊，也不得以版面暗示已知回程；回程日期只放日期組合行。
- **價格相關文案**：不得出現「價格以 Google Flights 頁面為準。」（R12）；不得單獨使用「訂票」；不得用「報價」「保證」「確定」等語；價格一律伴隨可見查到時間。
- 捏造或估算數字：價格、航班號碼、抵達時刻、+N／−N、轉機點、輪數、筆數。沒有資料就顯示「—」（舊資料）或不顯示該徽章，不用示意數字上線。
- 用 opacity 或淡色字降低停用／已結束內容的可讀性。
- 把免責聲明、取樣說明、來回說明句、人數總價、查到時間、徽章收進摺疊或縮小（完整清單見 2.5-B）。
- 同一頁重複免責聲明（每頁恰一次；逐列限定照樣逐列）。
