## 1. 裁定

### 1.1 chip 還是純文字行：**chip**

- 做法：一枚輪廓 chip，字面放在 chip 內。不用純文字行。
- 理由：
  1. chip 在放得下的狀態（持有中、1280、少一枚徽章時）**不多佔高度**；純文字行無論如何都要多一整行，且 P0 在首屏。
  2. 站內「事實型標籤」的語彙就是無填色的輪廓 chip（「資料截至 10-02」「美股（US）」）；有填色的 chip 是「狀態」（快取資料、未持有）。單位是事實，不是狀態，所以用輪廓、不填色。
  3. 純文字行的 `text-xs text-neutral-400` 是站內「註腳」的樣子，新使用者最容易略過；chip 外框讓它被讀成「標籤」。
  4. 與頁頭「美股（US）」同家族：市場是一個 chip，幣別是另一個 chip，語意對稱。
- **確切 class（一組，三處＋待決定處共用，只寫一次）**：

```
whitespace-nowrap rounded border border-neutral-700 px-1.5 py-0.5 text-xs text-neutral-300
```

  - 與既有「資料截至」chip（`rounded border border-neutral-700 px-1.5 py-0.5`）**同外形、同外框**，只差兩點：多 `whitespace-nowrap`（7～8 字不得標籤內折行，沿用首頁重排規範 §4「徽章之間換行，不在標籤內」）、文字用 `text-neutral-300`。
  - **`text-neutral-300`，不是 `-400`**：提案寫「`-400` 不得更淡」是下限，不是指定值。這枚標籤要回答的是「價格是不是新台幣」，是整件 F-7 的目的，不該和「資料截至」同亮度被一起略過。`text-neutral-300` 已被頁頭市場 chip 使用，不是新色階，不需修訂 style guide。frontend **不得**直接複製「資料截至」的 `text-neutral-400`。
  - 不加 `bg-*`（不填色，維持「事實」而非「狀態」）；不加 `title`、`aria-label`、`sr-only`、`opacity-*`；不加 `rounded-md`（與「資料截至」的 `rounded` 一致，與「未持有」的 `rounded-md` 區隔）。
- **無色相**：全部用 neutral 階，不用 sky／amber／rose。理由同 X-3c：站內語意已被占用（紅綠＝損益、橘＝違反、琥珀＝備援／無法評估、sky 為連結），單位不是警示。
- **深色模式**：站內只有深色（`globals.css` 固定 `--background: #0a0a0a`，原始碼無 `dark:`、無 `prefers-color-scheme`）。**不加任何 `dark:` 變體**，不設淺色版。
- 單一來源：class 放在一個匯出的小元件 `PriceUnitBadge`（建議檔案 `app/position/[symbol]/PriceUnitBadge.tsx`，內部以 `market → marketCurrency → 提案的 builder` 取字面），所有位置都用它，**不要把 class 字串複製到各檔**（X-3c 的教訓：日後調亮度會漏改）。

### 1.2 P0 決策卡徽章列：排**最後一枚**（未持有時第 4、持有時第 3）

順序：`資料截至` → `快取資料／狀態 chip` → （`未持有`）→ **`價格單位`**。
與提案預設（放在 `DataMetaStatusBadge` 之後、`NOT_HELD_BADGE` 之前）不同，理由：

1. 375 下未持有狀態一定換行（見第 0 節）。放最後，換行的是**新標籤自己**：第一行三枚既有徽章位置、寬度與現況**逐像素相同**，新標籤獨占第二行靠左。若放在「未持有」之前，被擠到第二行的會是「未持有」，它會離緊接在下的整句「未持有此標的，以最新收盤 183.73 試算…」遠一行，且既有版面被改動。
2. 單位標籤最後一枚，緊接下面那句含 183.73 的句子與四格數字，位置上最貼近數字。
3. 持有／未持有兩種狀態下，標籤都固定在徽章列最末，位置規則簡單。
4. DOM 順序仍在所有價格數字之前（徽章列在句子與四格之前），符合提案「標籤在第一個價格數字之前」。

實作：在 `DecisionCardBody` 徽章列 `<span className="flex flex-wrap items-center gap-1.5 text-xs text-neutral-400">` **內最後**加 `<PriceUnitBadge />`，閘門 `levels !== null`。**不改外層任何 class**（`gap-1.5` 同時是列間距，維持 6px）。

### 1.3 P1 技術分析、關鍵價位參考：chip 緊接 **h2**，不進右側徽章列

通則：**有 h2 的區塊，chip 緊接 h2 右側（同一個左群組）；沒有標題的決策卡，chip 排徽章列最後。** 兩個 P1 區塊用同一個規則。

**技術分析（`page.tsx` L235-283）**

### 3.2 class 與間距（逐字）

- chip：`whitespace-nowrap rounded border border-neutral-700 px-1.5 py-0.5 text-xs text-neutral-300`（唯一一份，寫在 `PriceUnitBadge`）。
- P0：沿用徽章列既有 `gap-1.5`，不改外層。
- P1 兩處左群組：`flex flex-wrap items-center gap-x-2 gap-y-1`。h2 class 不動。
- P1 關鍵價位：收盤 `<span>` 由 `text-sm text-neutral-400` 改為 `ml-auto text-sm text-neutral-400`，其他不動。
- P2：`<div className="flex">` 包 chip，間距靠既有 `space-y-3`。

### 3.3 換行規則

- chip 內永不折行（`whitespace-nowrap`）；換行只發生在徽章／群組之間，沿用首頁重排規範 §4。
- 不使用 `truncate`、`overflow-hidden`、`max-w-*`、`line-clamp`、`hidden`、`sm:hidden` 等任何會在窄寬隱藏或裁切 chip 的 class。
- 不為了塞進單行縮小字（維持 `text-xs`）、不縮小 `px`。
- 320 寬（非驗收範圍，記一筆）：決策卡內容寬約 254px，chip 98／110px 單獨一行放得下；關鍵價位第一行 214／226px 放得下。

### 3.4 深色模式

只有深色；不加 `dark:`，不新增 CSS 變數、不新增 Tailwind 自訂 token、不新增圖示或動畫。

### 3.5 vitest 可以釘住的部分

可釘（jsdom 可行）：
1. `PriceUnitBadge` 的 `className` 逐字等於 3.2 的 chip class；且 `position/[symbol]` 底下所有 `.tsx` 原始碼中，該 class 字串只出現在 `PriceUnitBadge.tsx` 一處（單一來源守門，防複製貼上）。
2. class 的 token 守門：含 `text-neutral-300`、`border-neutral-700`、`whitespace-nowrap`、`text-xs`、`px-1.5`、`py-0.5`、`rounded`；**不含** `text-neutral-400/500/600`、任何 `opacity-`、任何 `bg-`、任何彩色階（`red|rose|orange|amber|yellow|green|emerald|sky|blue|cyan|violet|purple|pink`）、`dark:`、`truncate`、`overflow-`、`hidden`。
3. 無障礙屬性：chip 元素沒有 `title`、`aria-label`、`aria-hidden`、`sr-only`、`role`。
4. 位置與順序（DOM）：
   - P0：chip 是徽章列的**最後一個子節點**，且在含價格的句子與四格之前（`compareDocumentPosition`）。
   - P1：chip 與 `<h2>` 同一個父節點、緊接其後；**chip 不是 `<h2>` 的子孫**；`getByRole("heading", { name: 原標題 })` 仍命中。
   - 關鍵價位：DOM 順序 h2 → chip → 收盤列；收盤 `<span>` 含 `ml-auto`。
   - P2：chip 是 details 容器第一個子節點，在 `ENTRY_E1_QUALIFIER` 之前。
5. 閘門：有價格才有、無價格（`levels === null`、bars 非 ok、`trend` 為 `unavailable`）時整個 chip 不在 DOM。
6. 數量：美股頁資料齊全時 DOM 內 chip 恰 4 枚（決策卡、技術分析、關鍵價位、六項觀察 details）；每個區塊恰 1 枚（不得出現兩枚）。
