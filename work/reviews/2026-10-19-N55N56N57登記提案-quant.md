**一、N-55：相位範圍**

先講事實：

- 【事實：§4.3 L1054–1055】(e) 寫「排程日的涵蓋率」，(f) 寫「作廢列 ÷（已結算列＋作廢列）」，兩者都沒有寫相位。

- 【事實：TA 1-A】`record_range` 回傳全部相位，逐列帶出「是否為第 0 相位格點」。
- 【事實：§4.7 L1293「重放的主樣本」】其他相位只作揭露、不作判定，已經有前例。

候選規則有三案：
- **A 案**：三項都只算第 0 相位。
- **B 案**：作廢率與涵蓋率算全部相位，W 只放回第 0 相位。
- **C 案**：三項都算全部相位，也就是 TA 擔心的讀法。

(1) 作廢率門檻（5%）的方向
- A 案和 B 案的期望值相近。差別在 A 案的分母只有 B 案的約 1/h，所以抽樣變異較大。
- 例子：n＝30 附近，一筆作廢約 3%，兩筆約 6%。
- 【推論】真實作廢機率低於 5% 時，A 案比較容易越過門檻；高於 5% 時，比較容易沒越過。所以是兩面。
- C 案的作廢率和 B 案相同。

(2) W 的方向
- 【推論：代數】W 下，模型點估計 ≤ 基準 B，若且唯若 k − k_B ≤ V。
- C 案的 V 約是 A 案的 h 倍。
- 例子（假設值，【推論】）：h＝5、n＝30、第 0 相位有 2 筆作廢，全部相位共約 10 筆。
  - A 案：模型要比 B 多贏超過 2 筆（約 6.7 個百分點），`fail_w` 才不成立。
  - C 案：要多贏超過 10 筆（約 33 個百分點）。
  - 所以在 C 案下，只要作廢率 > 5%，`fail_w` 幾乎必定成立。
- A 案相對 C 案是放寬面。

(3) F-2 的方向
- 【推論】`fail = fail_normal OR (void_rate > 5% AND fail_w)`。
- A 案相對 C 案，下架機會較小（放寬面）。
- A 案相對 B 案，只差在作廢率的變異，是兩面。

(4) 可操縱性
- 【事實】第 0 相位格點在 D_v 與 h 確定時就固定了（§4.1），作廢的判定不讀 label（§6.3 v0.22 註，L1531）。
- 【推論】三案在執行期都沒有挑選空間。
- 涵蓋率有一條設計期的管道：規則只在第 0 相位的難判日子輸出證據不足。這條管道在 B、C 案下會被其他相位稀釋約 h 倍，不容易看出來；A 案直接量測影響 n 的那組格點。

(5) 一致性
- **§4.1**：只有 A 案符合不重疊計數。C 案把重疊視窗的列混進不重疊樣本，同一段連續停牌也會被重複計數約 h 次（【推論】）。
- **§4.2 W**：「放回樣本」的樣本是 n 樣本，A 案就是這個樣本的最壞情境界。
- **§4.3 (f)**：作廢率決定 W 要不要套用。A 案下兩者用同一組列，作廢率就等於「判定樣本中被放回的比例」。B 案兩者用的是不同的列。
- **§4.3 (e)**：見 (4)。
- **§4.5 第 1 點**：A 案只在「E 內 T ≤ T\*_j」這個範圍內再限定。第 0 相位格點上、不在 P_j 內的作廢列與證據不足列照樣計入，所以 N-50 修掉的放寬（作廢率恆為 0、涵蓋率恆為 100%）不會回來。
- **ADR D-11.1「E 不分相位」**：A 案不改 E 的定義，做法和 n「在 E 內依 §4.1 計得」相同。

字面讀法的評估：字面讀不出唯一答案。脈絡上，V9-06 是寫在「n ＝ 主樣本中…」那一點底下的子句，支持 A 案；只看字句、不看脈絡則是 C 案。所以 A 案標「補定義（兩面）」，CEO 欄填明確同意。

**二、N-56：待重算列**

先講事實：
- 【事實：§6.3 L1638，N-29 (b) (i)】待重算的預測「不計入 n，也不計入命中率、W 與 §4.3 的任何判定；順延前的結果不得以任何形式計入任何驗證統計」。待重算集合「只依存下的序號與作業紀錄機械決定，不看預測內容或結果」。
- 【事實：L1637】更正作業「不改寫原結果，也不改記作廢」。
- 【事實：ADR L1328、L1784】待重算列的鏈尾是 `resolved`。
- 【推論】所以待重算列的鏈尾是順延前的結果。

候選規則有三案：
- **A 案**：分子和分母都不計入（字面）。
- **B 案**：計入分母的「已結算列」。
- **C 案**：當作作廢列，計入分子與分母。

方向：
- 作廢率的大小關係：V/(R+V+P) < V/(R+V) < (V+P)/(R+V+P)。也就是 B 案作廢率最低、C 案最高，A 案居中。
- 所以 A 案比 B 案嚴。這一點 TA 的推論是對的。
- W：A、B 兩案都不放回待重算列。C 案若放回，抵觸 L1638「不計入…W」。

checkpoint 與 daily 的差別：
- 【推論：由 U 與 n_complete 的定義】checkpoint 列上，T ≤ T\*_j 的待重算列只可能是 `unbounded_pending`，其他待重算列會讓閘門等待。
- 【事實：§4.5 第 2、4 點】`unbounded_pending` 有 T ≤ T\*_j 者時，正面結果不認列。
- 所以 A 案在 checkpoint 上的殘餘，只可能減弱負面結果，不會幫助正面結果。

可操縱性：
- 待重算集合由機械方式決定。
- 【推論】B 案下，更正作業中斷（§4.2「更正作業揭露」(v)）會延長待重算期間、稀釋作廢率。A 案沒有這條槓桿。

一致性：
- A 案就是 L1638 的字面，§4.3 (e)(f) 都屬於「§4.3 的任何判定」。
- B 案以順延前的 `status` 計分，抵觸 L1638。
- C 案改動風控已確認的 N-29 (b) (i)。

**三、§9.2 發現 (2)：多對象合併時沒有合格對象的決策日**

先講事實：
- 【事實：§4.1 V10-11 L997】作廢的對象「不在分母內，但在 W 中放回」。
- 【事實：L996】一個決策日要有至少一個合格對象才算一個樣本。
- 沒有合格對象的日子怎麼處理，字面沒有寫。

候選規則有兩案：
- **甲案**：這種日子成為 W 的樣本日（模型 0、基準 1）。
- **乙案**：這種日子不進 W。

分析：
- 方向：甲案比乙案嚴，W 的每日差值多一個 −1。作廢率不受影響。
- 可操縱性：【推論】一個日子有沒有合格對象，取決於當日其他對象的 label。乙案下，當日其他對象全部證據不足時，作廢對象就移出 W，W 放回的筆數會隨 label 改變。這正是 N-47 要封住的管道，也抵觸 V23-01 的 LG-34 (c)。甲案與 label 無關。
- 一致性：單一對象時，第 0 相位格點上的作廢列本來就是 W 的一個樣本點，甲案與它對稱。全部對象同日作廢（例如資料源中斷）的日子，也正是最該進 W 的情形。
- 另一面：當日只有一筆作廢時，這一整日由一筆列決定。
