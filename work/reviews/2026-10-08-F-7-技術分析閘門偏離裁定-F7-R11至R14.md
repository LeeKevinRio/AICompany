# F-7 技術分析閘門偏離裁定（F7-R11～R14）

- 審查者：risk-compliance-officer（唯讀；coordinator 轉錄，2026-10-08）
- 依據：第二版逐字審 `work/reviews/2026-10-08-F-7-幣別標示字面逐字審-F7-R1～R8-風控.md`、任務單 `work/dispatch/2026-10-08-任務單-F-7-個股頁原幣別價格幣別標示.md`
- 偏離內容：P1 技術分析閘門在 bars ok 但任一根 currency 不符時整個不印，不退回 signals 路徑（比第二版 F7-R3 字面更嚴）。

## 判定

**APPROVE WITH CONDITIONS（無 VETO）：接受更嚴版，不改回字面版。**

1. 實作較接近 F7-R2 原意（「任一根不符則整區塊無標籤」）。第二版 F7-R3「bars ok（套 R2）或 signals ok」照字面讀會與 R2 矛盾，屬風控第二版措辭瑕疵；實作朝 R2（fail-closed）解釋是對的。
   - signals 與 bars 走同一條取資料路徑（`backend/app/api/signals.py` L96、`backend/app/api/bars.py` L90 都呼叫 `load_bars`），signals payload 沒有 currency 欄位，前端無從核對。bars 已自己宣告有一根不是該市場幣別時，指標值與圖表來自同一批可疑資料。
   - 標籤放在 h2 旁，讀者會理解為整個區塊的單位；照字面版補印等於把資料層已承認不一致的東西說成確定，違反紅線「不得隱藏不確定性」。
2. 使用者面不需揭露（只會讓標籤在異常狀態少印，不新增字面）。CEO 需知悉、不需裁示（屬收緊；放寬才需 CEO 明確同意）。

## 條件

- **F7-R11（frontend-engineer，required）P1 閘門結構釘死。**
  - `page.tsx` 技術分析區塊（L246-250）維持三元式順序：bars ok 只走 bars 分支（逐根比對 currency）；bars 非 ok 才看 signals（ok 且有 payload，用 `PRICE_UNIT_MARKET_ONLY`）；兩者皆否不印。
  - 不得改成 `||`，不得在 bars 分支回 null 時退回 signals 分支。
  - 現有測試保留、期望不得改：`priceUnitBadge.test.ts` L734-742、L744-757。改閘門須回風控重審。
- **F7-R12（coordinator 轉錄、creative-lead 補提案紀錄，required，紀錄更正，不涉畫面字面）**
  - (i) F7-R3 閘門句以此取代：
    > 技術分析閘門：bars ok 時只套 F7-R2，逐根 currency 等於 F7-R1 表值才印；任一根不符則整區塊無標籤，不退回 signals 路徑。bars 非 ok 時，signals ok 且有 payload 才印，只套 F7-R1。兩者皆否不印。
  - (ii) 提案第四節「殘留與前提」（以第二版 F7-R7 為準）後補一句，交 CEO 知悉：
    > 另：日線資料自身宣告的幣別與市場不符時，該頁所有區塊（含技術分析「詳細」內的指標數值）一律不印價格單位標籤，價格數字照常顯示且無單位；此狀態只在資料層錯誤時出現，修正屬 F-9。
