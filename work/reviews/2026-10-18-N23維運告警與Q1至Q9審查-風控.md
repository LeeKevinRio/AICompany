## 一、本次結論

**審查結論：APPROVE（修改後核可），沒有 VETO。**

整份提案沒有保證性字眼，也沒有隱藏風險的表述；整體方向是收緊。不過有 4 件事，我判為 required：

1. **Q7 的共同守衛不存跨執行狀態，會自己解除。** 市場 DB 被還原之後，新寫入的 run 會讓 `MAX(run_id)` 再次追過參考值，判定就不再成立。這時結算、登記、更正作業會在「遺失了 run」的市場 DB 上恢復執行，而且不需要任何人處理。
   - 依 ADR-0026 D-9.4，主 DB 與市場 DB 要從同一組備份一起還原。所以 R 倒退只會在違規的單獨還原時出現。
   - 一旦出現，A-77 第 10 項的登記是永久的固定排除（ADR-0027 L976～L978）。
   - 字面三「處理終點不變：直到 devops-sre 處理」照現在的寫法，會讓人以為程式會鎖住，必須改成誠實的寫法。
2. **Q7 讓 `market_scan_restore_suspected = 1` 變成不可能出現**：第 8 點成立時，共同守衛一定成立。這會帶來兩個後果：
   - FL-64 (g)（L2245）「有其他觸發時作業照常啟動」與 Q7 直接衝突；
   - §4.2「可能不完整」揭露失去唯一的資料來源，揭露等於變弱，所以要補一個來源。
3. **Q2 只改了 `n_disclosure_masked`，沒有改 `pa9_holds`。**
   - L1487「依 RC′-2，遮蔽成立時 `pa9_holds` 必然為真」會變成不成立；
   - 族群閘門句經 `forward_n_below_min` 代入 LM-144 的路徑也會斷掉；
   - 我核可 LM-153 時，理由 ④ 依賴的就是這個不變式。
4. **字面四：rollback 之後重算完整清單時，不得重讀主 DB。** ④ 在交易內寫的登記已經隨 rollback 消失，重讀會把它們誤列為「未登記」，B-3 清單就不屬實。

#### Q2：`snapshot_stale`（必審；含 LM-153 重審）

**LM-153 重審結論：字面「驗證徽章的狀態待彙整」不改，仍然屬實，可以涵蓋 `snapshot_stale`。** 理由：

- 遮蔽成立時，最新觀察日的徽章內容確實還沒彙整，「待彙整」屬實。字面裡沒有「重新」「上次」，也沒有預告什麼時候恢復。
- 持續失敗時遮蔽沒有上限。這和 `e_changed_since` 遇上快照失敗時的情形相同，L2077 已經揭露並核可過。
- 條件 ⑪（遮蔽時不顯示方向）：大盤與個股依 C7-6 成立；族群則要以下面的 R-Q2-1 為前提。

`(b′)` 比 `(b)` 精確：以 `late_cutoff_at` 為界，不會每晚都遮蔽。方向是收緊，我採用。

- **R-Q2-1 required**：`pa9_holds` 要同步。
  - 定位字串（L1412，grep -o 唯一）：``為真時，`pa9_holds` 一律為真，直到之後產出一筆讀取序號涵蓋該事件的 daily snapshot 為止``
  - 在該子點之後、同一層插入：
  > - （N-23 Q2）`snapshot_stale(snapshot)` 為真時，`pa9_holds` 同樣一律為真，直到之後寫入一筆使 `snapshot_stale` 不成立的 daily snapshot 為止。查詢時傳入 `pa9_holds` 的 bool，取自同一次 `n_disclosure_masked` 判定所用的 `e_changed_since(snapshot)` 或 `snapshot_stale(snapshot)`，兩者在同一個 read transaction 內判定；寫入 snapshot 當下照舊以 False 呼叫。所以「遮蔽成立時 `pa9_holds` 必然為真」對三種 `mask_reason` 都成立。

  實作機制 TA 可以調整，但這個不變式不得改。
- **R-Q2-2 required**：Consequences 要揭露成本。
  - 定位字串（L2077，唯一）：`snapshot 作業失敗時，遮蔽會持續到下一筆 snapshot 成功為止。`
  - 在句末接：

  - L2494：`族群 × 兩種遮蔽情形` → `族群 × 三種遮蔽情形`
  - L2496、L2499（兩處）：``× {`e_changed_since`, 沒有 snapshot}`` → ``× {`e_changed_since`, 沒有 snapshot, `snapshot_stale`}``
  - L2624：``× `mask_reason` 兩值`` → ``× `mask_reason` 三值``
  - L2626：`兩格的渲染結果逐位相同` → `各格的渲染結果逐位相同`
  - 在 L2630 (m6) 之後插入：

#### Q7：還原疑似時的共同守衛（必審；判方向）

**方向判定：**

- **缺日稽核一面：收緊。核可，不需要 CEO。**
