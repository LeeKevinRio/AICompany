## 視覺抽查
| 項目 | 規範 | 實測 |
| --- | --- | --- |
| B 文字 class | 不淡於 `text-sm text-neutral-300` | `text-sm text-neutral-300`，oklch(0.87 0 none)，14px，400 |
| B 右側 span | 不渲染 | 容器 descendants 只有 1 個（`<p>`），符合 |
| B 容器 | 不得截斷 | sw/cw 相同，overflow visible |
| 容器只剩一個子元素 | `flex flex-wrap justify-between` 不得造成問題 | 見下 |

- 容器只剩一個子元素：
  - 沒有造成版面問題。`<p>` 是 flex item，用 `justify-between` 時單一子元素靠左（start）。
  - 1280 的截圖是靠左單行，沒有被撐開或置中。375 文字在容器內換行，兩行都在 padding 內，沒有溢出。
  - `flex-wrap` 和 `justify-between` 在單一子元素時是無作用的冗餘 class。
  - 觀察：這是死 class，可選擇性清理，不構成缺陷，也不擋件。
