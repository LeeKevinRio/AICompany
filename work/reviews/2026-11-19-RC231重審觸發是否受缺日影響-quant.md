# quant-researcher 回覆 RC-231：重審觸發區塊是否也要納入缺日加註

## 結論

**必須把加註的範圍擴及重審觸發區塊。**

- n̂ 與 T1 和「格點數值」用的是同一個格點函式，缺 T 失去格點時，三者會一起受影響【已證實】。
- n̂ 一般高估正式 n，但缺日會使它暫時偏低，偏差約為每個缺日一個格點，T1 因此可能較晚成立。這是不保守的方向。這種情況下，固定註記裡的「近似上界」不一定成立【推論】。
- 特徵跨過缺口不影響 n̂。
- 重審觸發區塊的數值全部不存帳，影響只在顯示，日後可重算。

## 1. 哪些數值會與日後重算的結果不同

**c₁**：不會。它是已登記 definition 的第一個檢查點（`store.py:1409-1437`）【已證實】。

**D_v**：不會。它取第一筆 `late=0` 紀錄的 T，驗證層同樣從紀錄讀【推論】。

**d₁ 與 T2**：不會。d₁ 是 D_v 加上 c₁×h 個週一至週五，不扣休市日，與快照的 session 無關（`store.py:1440-1450`）【已證實】。

**n̂、T1，以及執行狀態區塊的「第 0 相位格點數／沒有紀錄的格點數」**：會。

- 三者都來自 `phase0_grid`。格點取自「所有快照的定案 session 聯集」，從 D_v 起每第 h 個 session 取一個（`store.py:1356-1397`、`store.py:438-450`）【已證實】。
- 來源永久缺席的 session 不在聯集裡，所以從缺口起所有格點都會錯開一個相位，「其後第 h 個 session」實際上也變成 h+1 個交易日【已證實：依程式推得】。
- 驗證層改按官方交易日曆重建格點時，結果會不同。
- 合成推演（只數格點，不涉及任何標籤）：h=3 時，n̂ 可能比日曆格點多 1，也可能暫時少 1【推論】。

**特徵跨過缺口**：不影響 n̂。

- n̂ 只計「有 `late=0` 紀錄、而且其後第 h 個 session 已出現」的格點，不扣 `insufficient` 與作廢，也與標籤無關（`store.py:1398-1407`）【已證實】。
- 缺口一般也不會改變紀錄是否判 `insufficient`【推論】：
  - 抓取範圍是 500 個日曆日（`recorder.py:134`），根數遠多於 121，`E-BARS-SHORT` 不會因少一根而觸發。
  - 相鄰兩根 bar 仍能算出日報酬，σ_d 的有效數不會變少。
- 不過，若驗證層日後把「輸入窗含缺日」的紀錄判為作廢，正式 n 會變小，n̂ 的高估會更明顯。這個方向是保守的。

## 2. 偏離的方向

- **一般情況**：n̂ 不扣任何東西，所以高於正式 n，T1 會提早成立。重審提早是保守的方向，ADR-0030 L299 的說法是「提早設計驗證層反而能減少……誘因」。
- **缺日造成的偏離**：n̂ 可能暫時偏低，T1 晚約 h 個 session 才成立。這是不保守的方向，而且讓 `N_HAT_NOTE`（`report.py:94`）的「近似上界估計」在這種情況下不一定成立【推論】。
- **實際影響有限**：h3 的 T2 約在 D_v 後 36 天（ADR-0030 L299），通常早於 T1。T2 不受缺日影響，所以觸發時點實際上由 T2 兜底【推論】。

## 3. 加註至少要多表明的事

依指示不擬字面。加註至少要多表明三件事：

- 重審觸發用的 n̂，以及依它判定的 T1，可能與日後驗證時重算的結果不同。
- 偏離的方向不一定，可能偏低。也就是在這種情況下，「近似上界」不一定成立。
- 可選：c₁、d₁、T2 不受資料來源缺日影響。

## 4. 只是顯示，還是會影響帳內不可改的值

- **重審觸發區塊**：只是顯示。n̂、T1、T2、d₁ 都由唯讀查詢即時導出，不寫入帳（ADR-0030 D-8 第 4 點）【已證實】，驗證層重算即可修正。
- **唯一不可逆的事件**：T1 首次成立時，recorder 記的 WARNING log 時點，以及因此啟動驗證層 ADR 起草的時點。
- **帳內真正不可改的值**：在每筆紀錄的特徵、label、σ_d、`band_def`、基準欄位上。這是前一題已經分析的問題，不屬本題範圍。依 V32-03（事先宣告 L1113），驗證層不得回頭改寫這些值，只能標記並揭露。
