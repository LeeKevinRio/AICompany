## coordinator 實測（2026-11-10，Python sqlite3 3.45.1，`:memory:` 暫存 DB）

歷程表的 CHECK 約束：`value INTEGER NOT NULL CHECK (value IN (0,1))`、`changed_on TEXT NOT NULL CHECK (date(changed_on) IS changed_on)`。

```
1 '2026-11-10' ok
'1' '2026-11-10' ok
1.0 '2026-11-10' ok
2 '2026-11-10' REJ IntegrityError
0.5 '2026-11-10' REJ IntegrityError
'x' '2026-11-10' REJ IntegrityError
1 '2026-13-01' REJ IntegrityError
1 '2026/11/10' REJ IntegrityError
1 '2026-11-10 ' REJ IntegrityError
pragma insert ok ('x', 'text', 'bad')
```

- `CHECK (date(changed_on) IS changed_on)` 可用，會拒絕不存在的日期、斜線格式與結尾空白。
- `value` 寫入 `1`、`'1'`、`1.0` 時，經 affinity 轉成 integer 1 後被接受；寫入 2、0.5、`'x'` 會被拒。
- 開啟 `PRAGMA ignore_check_constraints = ON` 後，可以種入壞列，fixture 的用法成立。
- 以上只是佐證，不取代 dev-lead 的測試。
