### 給 devops-sre 的介面說明

```python
read_twii_bars(copy_path: Path) -> list[PriceBar]      # ascending, as_of injected
copy_uri(copy_path: Path) -> str                       # "file:...?mode=ro[&immutable=1]"
injected_as_of(day: date) -> datetime                  # 20:00 Asia/Taipei
required_sessions(definition: DirectionDefinition, rules: Iterable[PlaceholderRules] = (P0, P1)) -> int
check_depth(bars: Sequence[PriceBar], *, run_date: date, required: int) -> None
bars_sha256(bars: Iterable[PriceBar]) -> str
class AcceptanceStop(Exception): kind: StopKind        # str(e) == STOP_SENTENCES[kind]
StopKind = Literal["no_rows", "unparseable_row", "demo_source", "foreign_source", "cache_short"]
STOP_SENTENCES: Mapping[StopKind, str]                 # ASCII, no digit / path / value
```

**例外種類**

| kind | 何時拋出 |
|---|---|
| `no_rows` | 沒有 `^TWII` / `TW` 列 |
| `unparseable_row` | 任一列無法解析 |
| `demo_source` | 任一列來源以 `demo` 開頭 |
| `foreign_source` | 任一列來源不是 `yfinance` |
| `cache_short` | 由 `check_depth` 拋出，執行日前的 session 數不足 |

**建議呼叫順序**
1. `bars = read_twii_bars(複本)`
2. 刪除複本（RC-158c）
3. `check_depth(bars, run_date=report.taipei_date(wall_clock()), required=required_sessions(definition()))`
   - `run_date` 的算法與 harness 相同。
4. `bars_sha256(bars)`
5. `run_acceptance(..., bars=bars)`

**加 RC-162 hooks 時要注意**
- hooks 要放在檔頭的 `sys.path` 區塊與所有 `app` / `tests` import 之前。
- 我的測試在 pytest 行程內載入這支模組。加入 hooks 後，請讓 `_load()` 保存並還原三個 hook 與 warnings filter，或改成在子行程載入。
