### 項 1｜X2 確認後「從觀察日移除、T+h 順延」：APPROVE WITH CONDITIONS

接受順延，不要求改成作廢路徑，也不要求順延筆數進 W。理由：
- **順延算出的是定義上正確的標籤，不是替代值。** §1.4（L394）把結算日定義為「實際觀察到的第 h 個交易日」。d 被確認不是交易日，正確的 T+h 本來就是順延後那一天，而且那根 bar 拿得到。等 5 天再作廢這條路，是給「正確值取不到」的情形用的；套到 X2 上，等於把算得出來的標籤丟出計分，違反底線 ①。
- **放寬那一面沒有挑資料的空間。** 能直接確認 X2 的只有「正面休市證據＋市場 DB 沒有 session」，判定是機械的、不讀結果（L1127），順延也不看方向。W 是作廢列的最壞情境，順延列的標籤是有效的，放進 W 反而會失真。
- **方向標示屬實**：「補定義（兩面）」，相對 v0.9 沒有放寬。順延之後再依 `missing_bar_after_wait` 作廢的照常計入（L1142）；結算後才確認的走 supersede（L1140）；兩條路徑都已寫明。

**條件 R-C（commit 前，required）**：
- 每一筆順延的結算列（結算前確認的）和 supersede 列（結算後確認的），都要記下四項：原 T+h 日期、被移除的 d、順延後的 T+h、X2 判定紀錄的參照。
- 理由：L1142 只承諾揭露筆數。沒有逐列標記，qa 就無法核對筆數，也無法證明沒有默默改結算日，這是底線 ② 的要求。
- 方向：收緊（稽核性）。

### 項 2｜「只有非收盤欄位有誤時只更正診斷欄位」延伸到 X3／X4：APPROVE

- 理由和我給 X1 的 (a) 相同：大盤標籤只用 P(T)、P(T+h) 的收盤。X3／X4 經獨立來源比對、收盤相符時，讓整根 bar 作廢，又會打開「波動劇烈日容易出資料問題、就被排除」的管道。
- 方向標「收緊」並寫出另一面（作廢較少），可以接受。
- 讀法確認：L1134 的「只有非收盤欄位不符」必須以「獨立來源的收盤已比對而且相符」為前提。獨立來源沒有公布收盤或某個欄位時，該列維持異常待查證，不得推定為「只有非收盤欄位有誤」。現行文字的意思已經是這樣，不另外要求修改。

### 項 3｜X2 新判準：APPROVE WITH CONDITIONS

逐條對照我的 v0.10 底線：
- **(a) 對照日曆不含受檢 bar**：到位。L1118 明文排除任何指數 bar，也不用 D-8.1、不讀 `ObservedSessionCalendar`；LG-25 (f) 以呼叫簽章斷言。
- **(b) 只憑正面證據直接確認**：到位。L1123 要求 (i)/(ii) 成立，而且市場 DB 沒有 session。只有 (iii) 成立，或證據矛盾，都列為待查證；待查證期間照原值計分、照常算觀察日，這是保守的做法。颱風停市之類不在休市日表上的情形，會落入「只有 (iii)」，走查證，也正確。

**和 R3-11 的差異（R-A、R-B，commit 前 required）**：

**R-A｜(iii) 與「市場 DB 有／沒有 session」改用 A-77 (i) 的定義。**
- 【事實】TA r3 的 A-77 (i) 是「有 ok bars run、而且該 run 的 `recorded_at ≥ final_after(TW, session)` 的 session」。A-78 也規定 D-8.1 (i) 只認定案後的 run。
- 現行草案寫「市場 DB 在 d 有／沒有 ok session」，連定案前的 run（啟動過早的 capture）也算。後果有兩個：
  - 平日 d 只有定案前 run 時，X2 不會觸發，但 R3-11 第 3 點要求這種情形列為異常待查證。
  - 週末 d 只有定案前 run 時，草案會算成證據矛盾、列待查證；R3-11 下則是直接確認。
- 最小改法：凡是 X2 裡的「市場 DB 在 d 有／沒有 ok（bars 的）session」，一律改成「d 在／不在 ADR-0027 D-8.1 (i)，也就是市場 DB 有／沒有 `recorded_at ≥ final_after(TW, d)` 的 ok bars run（A-77 (i)、A-78）」。不得另寫一份時點比較。
- 要改的位置：
  - L1118 (iii)，以及其中「只用市場 DB 的 ok session 集合」；
  - L1123 三處：「沒有 ok session」兩處、「有 ok session」一處；
  - L1143「決策日 T 依 §1.4 必須是市場 DB 的 ok session」，改為「必須在 D-8.1 (i)（A-75 (i)）」；
  - L74 修正清單、L1382 §9.3 第 18 點 (i)、L1383 V10-17 第 ③ 點補註，同步改字；
  - L1690 LG-25 (f) 改字，並加兩個 fixture：平日只有定案前 ok run → 異常待查證；週末只有定案前 ok run → 直接確認。
