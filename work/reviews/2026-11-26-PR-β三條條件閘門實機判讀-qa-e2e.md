- **來源：這是本來就有的建議卡字面，不是 PR-β 改出來的。** 有兩處，各自讀不同欄位。
  1. 可見的 summary 列「建議卡 命中 0 條」：
     - 位置在 `apps/stock-desk/frontend/app/position/[symbol]/page.tsx:580`，呼叫 `buildAdviceHitCount(advice.data.advice.matched_rules.length)`。
     - 字面來自 `apps/stock-desk/frontend/app/lib/oneLinerWording.ts:36-38`。
     - 這一行在截圖中是直接可見的，不需要展開。代跑者說它在「未展開 details 內」，不精確，它在 `<summary>` 裡。
  2. details 內的「規則共 0 條，可評估 0 條，命中 0 條，資料完整度 100.00%。」：
     - 位置在 `.../position/[symbol]/AdviceCardView.tsx:254-259`，讀 `advice.evaluation.total_rules`、`evaluated_rules`、`matched_rules`、`data_completeness`。
     - 這些值直接來自後端回傳的 advice。
     - 這次畫面上的 0 與 100% 是代跑者 fixture 的合成值（`genfix.js:46`：total_rules 0、completeness 1）。真實後端在壞值下會回什麼，這次無法驗收。

  - 我也沒有看 base 版本的畫面，所以「現況本來就有」是依原始碼與 diff 範圍判斷，不是實機對照。
