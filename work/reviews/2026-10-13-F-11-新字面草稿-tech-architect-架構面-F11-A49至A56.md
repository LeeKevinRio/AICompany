- **F11-A-51（表內計數列的資料來源，與 A-42 對齊）**
  - 策略欄的兩個計數只能讀 `round_trip_detail.<segment>` 內、與該段清單和 n 同一次 `attribute_round_trips` 呼叫產生的欄位。不得從 `PerformanceMetrics` 或 `curves` 推得，前端也不得加總或相減（A-24）。

- **F11-A-52（新增列的標籤不得擠壓既有列）**

- **F11-A-53（定義列的通用規則；確認 L-04n）**
  - 定義列只限下列四個錨點：最長連續虧損回合數（L-04n）、盈虧比（L-06d，L-06r 同格）、獲利因子（L-07）、在場時間比例（L-08n）。

  - 定義列是單一種列型（例如 `kind: "definition"`），前端只有一條渲染路徑，不為個別定義句寫特例。

- **F11-A-54（L-14 空狀態代碼只依計數判定；補充 A-13(a)，與 A-43 對齊）**
  - 判定函式放在 `report.py`，簽章只接收歸屬物件，例如 `round_trip_empty_state(attribution: RoundTripAttribution) -> Literal["no_position", "excluded_only"] | None`。這樣在型別層面就無法讀取在場判定、`weights`、`trades`、`coverage` 或 folds。
  - 真值表（窮舉且互斥）：

    | 條件 | 代碼 |
    |---|---|
    | `stats.n > 0` | `None` |
    | `n == 0` 且 `excluded_boundary_trips + open_trip_at_end == 0` | `"no_position"` |
    | `n == 0` 且兩者合計 > 0 | `"excluded_only"` |

  - 傳入的物件必須與該段清單、n、兩個計數是同一次呼叫的結果（A-42）。
  - 對任何輸入都不得拋錯（A-43）。
  - 後端參數化測試至少包含：
    - (a) 全段無交易 → `no_position`；
    - (b) AC-10 後例（唯一回合跨界被排除，在場比例 > 0）→ `excluded_only`；
    - (c) **在區段最後一根進場**（之後平倉或到最後仍未平倉）→ `excluded_only`，且該段在場區間數為 0；
    - (d) **前一區段進場、在本區段第一根出場**（`exit_idx == start`，依 L245 計入跨界；出場後空手，所以區間 s 不在場）→ 本段 `excluded_only`，且在場區間數為 0〔依定義推得，未實跑〕；
    - (e) n > 0 → `None`；
    - (f) 單向不變式：代碼為 `no_position` 時，在場區間數必為 0（可計算時）。理由：任一在場區間都意味著有回合與本段重疊，必會被計入。**不得斷言反向**（`excluded_only` ⇒ 在場 > 0），(c)(d) 就是反例。
  - 前端只做代碼 → 字面的對應，不得比較計數（A-23 的原始碼掃描涵蓋）。
  - 代碼識別字可以沿用，但後端 docstring 與 PRD FR-10 改以計數定義，不再用「有沒有部位」定義。AC-10 的「後例大於 0%」標明只是該 fixture 的事實，並補上 (c)(d) 兩例。

- **F11-A-55（O-9：定義列的可讀性方案與幾何驗收）**
  - 採方案 C。捲動容器宣告 `container-type: inline-size`。定義列的 `td` 取消內距，內層區塊設定：水平 sticky `left: 0`、寬度等於容器可視寬度（`100cqw`）、`text-sm`、自帶內距。

  - 以原始碼測試釘住：`sticky` 只能出現在定義列的內層區塊，而且只搭配 `left-0`。
  - 驗收（qa-e2e，375 與 1280 各測一次）：
    - (G1) 頁面層級沒有橫向捲動；
    - (G2) 捲動容器 `scrollLeft` 分別為 0 與最大值時，每個定義區塊的 bounding rect 水平方向都完整落在容器的可視範圍內（±1px）；
    - (G3) 定義區塊 `scrollWidth ≤ clientWidth`，計算後字級 ≥ 14px，不在 `<details>` 內；
    - (G4) 定義列 `<tr>` 是錨點 `<tr>` 的下一個兄弟節點；
    - (G5) 符合 A-52 的基準量測。
  - 已知後果：V2 加入長句整列之後，1280 寬時表格寬度會擴到整個 section（目前是依內容縮放）。欄寬不屬於「原位」的定義，但 AC-18 的 1280 截圖要確認既有列「不被截斷、不因折行影響閱讀」。
  - 方案 C 若在任一目標瀏覽器不符 G2／G3，或風控不接受 sticky：改走方案 D，並回送 L-C8-3 審查。不得退回方案 A 或 B。
