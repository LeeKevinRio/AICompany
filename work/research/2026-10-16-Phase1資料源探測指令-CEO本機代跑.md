## 0. 怎麼用（先讀）

### 0.1 一般守則（違反任一條請停手回報）

1. **只做唯讀 GET**。沒有 POST、沒有登入、沒有表單送出。
2. **限速**：每支請求之間 `sleep 6` 秒（`PROBE_SLEEP` 可調大，不要調小）。全部跑完約 70 次請求，單一指令區塊對同一網域通常不超過 15 次。
3. **不得大量下載**：每支指令都是單檔、單月或單檔個股；不要自行改成全市場逐檔迴圈、不要改長日期範圍。
4. **遇到 HTTP 403／429／503 就停**：helper 會自動建立 `$PROBE_DIR/.STOP`，之後所有 probe 會拒絕執行。不要重試、不要換 IP，等 15 分鐘以上、把狀況回報後再說。
5. **不跟隨轉址**（不加 `-L`）。看到 3xx 把 `redirect_url` 欄位回報即可。
6. **不要用 `set -x`、`curl -v`、`--trace`**：會把展開後的 token 印到畫面。
7. 需要金鑰的只有 FinMind：由 CEO 自行在本機終端機設定環境變數 `FINMIND_API_TOKEN`，**不要把它貼回對話、不要寫進任何檔案**。指令裡一律寫 `$FINMIND_API_TOKEN`。
   設定方式（先輸入 `bash` 進入 bash；貼上時畫面不會顯示）：

   ```bash
   # Read the token silently into this terminal session only; never write it to a file.
   read -rs FINMIND_API_TOKEN; export FINMIND_API_TOKEN
   ```

8. 本文件所有輸出只存在本機資料夾 `~/stock-desk-probe-2026-10-16/`，**不要放進 repo 的 `apps/stock-desk/backend/data/`**。

### 0.2 建立資料夾與 helper（每個新終端機視窗先確認 `$PROBE_DIR` 有設定）

```bash
# Create the probe folder and write the helper library (idempotent).
export PROBE_DIR="$HOME/stock-desk-probe-2026-10-16"
mkdir -p "$PROBE_DIR"/{common,t107,t108,t109,t110}

cat > "$PROBE_DIR/probe_lib.sh" <<'EOF'
# probe_lib.sh -- read-only GET helpers for the Phase 1 data-source probes.
# Rules baked in: GET only, fixed sleep between requests, no redirects followed,
# no secrets written to disk, hard stop on 403/429/503.
PROBE_DIR="${PROBE_DIR:-$HOME/stock-desk-probe-2026-10-16}"
PROBE_UA="stock-desk-probe/1.0 (personal research, read-only, low rate)"
PROBE_SLEEP="${PROBE_SLEEP:-6}"
PROBE_LAST_CODE=""

# probe <subdir> <name> <url> [extra curl args...]
probe() {
  local sub="$1" name="$2" url="$3"
  shift 3
  mkdir -p "$PROBE_DIR/$sub"
  if [ -e "$PROBE_DIR/.STOP" ]; then
    echo "SKIP $sub/$name: $PROBE_DIR/.STOP exists (block or rate limit seen earlier)."
    echo "     Wait at least 15 minutes, then: rm \"$PROBE_DIR/.STOP\""
    PROBE_LAST_CODE="skipped"
    return 1
  fi
  local meta code
  meta=$(curl -sS --connect-timeout 10 --max-time 45 -A "$PROBE_UA" \
    -D "$PROBE_DIR/$sub/$name.headers.txt" -o "$PROBE_DIR/$sub/$name.body" \
    -w '%{http_code}\t%{size_download}\t%{time_total}\t%{content_type}\t%{redirect_url}' \
    "$@" "$url") || meta=$(printf 'curl_error\t0\t0\t-\t-')
  code="${meta%%$'\t'*}"
  PROBE_LAST_CODE="$code"
  printf '%s\t%s\t%s\t%s\n' "$(TZ=Asia/Taipei date '+%F %T %z')" "$sub/$name" "$meta" "$url" \
    | tee -a "$PROBE_DIR/_index.tsv"
  case "$code" in
    403|429|503)
      touch "$PROBE_DIR/.STOP"
      echo "STOP: HTTP $code received. All further probes are disabled. Do NOT retry; report back." ;;
  esac
  sleep "$PROBE_SLEEP"
}

# probe_try <subdir> <name> <url1> <url2>: url2 is requested only if url1 is not HTTP 200 JSON
probe_try() {
  probe "$1" "$2" "$3"
  local first
  first=$(head -c 1 "$PROBE_DIR/$1/$2.body" 2>/dev/null)
  if [ "$PROBE_LAST_CODE" != "200" ] || [ "$first" = "<" ] || [ -z "$first" ]; then
    echo "  -> primary URL not usable (code=$PROBE_LAST_CODE); trying alternate URL once"
    probe "$1" "$2.alt" "$4"
  fi
}

# fm <subdir> <name> <dataset> [key=value ...]: FinMind v4 data GET; token comes from the environment only
fm() {
  if [ -z "${FINMIND_API_TOKEN:-}" ]; then
    echo "SKIP fm $2: FINMIND_API_TOKEN is not set in this shell"
    return 1
  fi
  local sub="$1" name="$2" ds="$3"
  shift 3
  local args=(-G --data-urlencode "dataset=$ds") kv
  for kv in "$@"; do args+=(--data-urlencode "$kv"); done
  if [ "${FM_TOKEN_MODE:-header}" = "param" ]; then
    args+=(--data-urlencode "token=${FINMIND_API_TOKEN}")
    probe "$sub" "$name" "https://api.finmindtrade.com/api/v4/data" "${args[@]}"
  else
    probe "$sub" "$name" "https://api.finmindtrade.com/api/v4/data" \
      -H "Authorization: Bearer ${FINMIND_API_TOKEN}" "${args[@]}"
  fi
}

# jsonshape <subdir/name>: print top-level shape of a saved JSON body (keys, list lengths, first/last element)
jsonshape() {
  python3 -I - "$PROBE_DIR/$1.body" <<'PY'
import json, sys
p = sys.argv[1]
try:
    raw = open(p, 'rb').read()
except OSError as e:
    print('NO_FILE', e)
    sys.exit(0)
try:
    d = json.loads(raw.decode('utf-8-sig'))
except Exception as e:
    print('NOT_JSON', type(e).__name__, '| first 120 bytes:', raw[:120])
    sys.exit(0)
def short(x, n=300):
    s = json.dumps(x, ensure_ascii=False)
    return s if len(s) <= n else s[:n] + '...'
if isinstance(d, list):
    print('list len=%d' % len(d))
    if d:
        print('first:', short(d[0]))
        print('last :', short(d[-1]))
elif isinstance(d, dict):
    print('dict keys:', list(d.keys())[:20])
    for k, v in d.items():
        if isinstance(v, list):
            print('  [%s] list len=%d' % (k, len(v)))
            if v:
                print('    first:', short(v[0]))
                print('    last :', short(v[-1]))
        elif isinstance(v, dict):
            print('  [%s] dict keys=%s' % (k, list(v.keys())[:15]))
        else:
            print('  [%s] = %s' % (k, short(v, 120)))
PY
}

# hdrs <subdir/name>: print only the time-related response headers
hdrs() {
  grep -iE '^(HTTP/|date:|last-modified:|age:|etag:|cache-control:|expires:|content-type:|x-ratelimit|retry-after)' \
    "$PROBE_DIR/$1.headers.txt" | tr -d '\r'
}

# timing_run <label>: one polling round for "when is today's close published" (3 GET requests)
timing_run() {
  local lbl="$1" ym roc tp_month f
  ym="$(TZ=Asia/Taipei date +%Y%m01)"
  tp_month="$(TZ=Asia/Taipei date +%Y/%m/01)"
  roc="$(( $(TZ=Asia/Taipei date +%Y) - 1911 ))/$(TZ=Asia/Taipei date +%m/%d)"
  echo "== timing_run $lbl | Taipei now: $(TZ=Asia/Taipei date '+%F %T %z') | looking for ROC date: $roc"
  probe t107 "timing_${lbl}_twse_stock_day_2330" \
    "https://www.twse.com.tw/exchangeReport/STOCK_DAY?response=json&date=${ym}&stockNo=2330"
  probe t107 "timing_${lbl}_twse_fmtqik" \
    "https://www.twse.com.tw/exchangeReport/FMTQIK?response=json&date=${ym}"
  probe t107 "timing_${lbl}_tpex_6147" \
    "https://www.tpex.org.tw/www/zh-tw/afterTrading/tradingStock?code=6147&date=${tp_month}&id=&response=json"
  for f in twse_stock_day_2330 twse_fmtqik tpex_6147; do
    printf '%s\t%s\t%s\t' "$(TZ=Asia/Taipei date '+%F %T')" "$lbl" "$f"
    if grep -q "$roc" "$PROBE_DIR/t107/timing_${lbl}_${f}.body" 2>/dev/null; then
      echo "TODAY_ROW_PRESENT"
    else
      echo "today_row_absent"
    fi
  done | tee -a "$PROBE_DIR/t107/timing_summary.tsv"
}
EOF

# Syntax check only (does not run any request).
bash -n "$PROBE_DIR/probe_lib.sh" && echo "probe_lib.sh syntax OK"
```

helper 說明（給判讀用）：

- 每次 `probe` 會在終端機印一行、同時附加到 `$PROBE_DIR/_index.tsv`，欄位依序為：台北時間、`子資料夾/名稱`、`http_code`、`size_download`、`time_total`、`content_type`、`redirect_url`、URL。**這個 `_index.tsv` 不含任何金鑰（FinMind 走標頭，不進 URL），可整份貼回。**
- 每個回應存成 `名稱.body`（本體）與 `名稱.headers.txt`（回應標頭），原檔留在本機。
- `probe_try` 用在「我不確定主站或新站哪個路徑還活著」的地方：第一個 URL 不是 HTTP 200 JSON 才會打第二個。
- `fm` 預設用 `Authorization: Bearer` 標頭帶 token（避免 token 進 URL 與 `_index.tsv`）。若 FinMind 回 `status` 非 200 且訊息指向 token 無效，改用 `export FM_TOKEN_MODE=param` 再重跑該支（現行 adapter 用的是 query 參數，見 `app/data/providers/finmind.py`）；此模式下 token 仍不會寫進 `_index.tsv`。**請把「標頭模式是否可用」寫進回貼。**

```bash

# 1) Catalogue files (Swagger/OpenAPI spec) of both exchanges. 404 on either path is an acceptable outcome; report it.
probe common twse_openapi_swagger "https://openapi.twse.com.tw/v1/swagger.json"

probe common tpex_openapi_home "https://www.tpex.org.tw/openapi/"

# 3) List "path <TAB> summary" from a saved swagger file (jq if available, python3 -I as fallback).
list_paths() {
  if command -v jq >/dev/null 2>&1; then
    jq -r '.paths | to_entries[] | "\(.key)\t\(.value.get.summary // "")"' "$1"
  else
    python3 -I -c '
import json, sys
d = json.load(open(sys.argv[1], encoding="utf-8"))
for p, v in sorted(d["paths"].items()):
    print(p + "\t" + (v.get("get") or {}).get("summary", ""))
' "$1"
  fi
}
list_paths "$PROBE_DIR/common/twse_openapi_swagger.body" > "$PROBE_DIR/common/twse_paths.tsv"
list_paths "$PROBE_DIR/common/tpex_openapi_swagger.body" > "$PROBE_DIR/common/tpex_paths.tsv"

# 5) License / terms evidence: the 'info' block of each spec plus any terms-like links on the landing pages.
for f in twse_openapi_swagger tpex_openapi_swagger; do
  echo "--- $f info ---"
  jq -c '.info' "$PROBE_DIR/common/$f.body" 2>/dev/null || head -c 600 "$PROBE_DIR/common/$f.body"

for f in twse_openapi_home tpex_openapi_home; do
```

### 1.2 要驗證的問題

1. 端點：哪個路徑真的回 JSON？HTTP 狀態？回應 `Content-Type` 與編碼？
2. 年份範圍：2024、2025、2026、2027 各年是否有資料？**2027 在 2026-10 是否已公布**（決定 `valid_until_session` 能往前算多遠）。
3. 欄位：有無日期、名稱（休市原因）、說明、是否含「補班」「結算日」「最後交易日」等；日期格式是西元還是民國（例如 `1150101`）。
4. 臨時休市：2024-10 的 `holidaySchedule` 與 `FMTQIK`（單月成交日清單）是否一致？不一致處即「表上沒有、但實際沒開市」的日子，直接回答 AC-B5b-2（颱風假）能否只靠官方表。
5. 授權條款與額度：OpenAPI／官網有無 rate limit 說明、使用條款、是否允許快取與衍生顯示。
6. 時間欄位與時區：回應標頭 `Date`（GMT）與台北時間的換算；回應本體內有無更新時間。
7. point-in-time：此表是否會被事後更正？沒有版本時間戳的話，只能由我們自己存快照（抓取時間 + sha256）。本次先取一次快照，約一個月後建議重抓一次比對（後續動作，不在本次範圍）。

### 1.3 指令一：休市日表與交叉驗證（約 12 次請求）

```bash
s6_clear() {  # s6_clear <name>: remove a stale body/header pair so a skipped probe cannot be mistaken for a fresh one

# s6_extract <label> <src> <body-file> <iso-date> <roc-date>
# Appends one line to bars_by_round.tsv: taipei-time, label, src, today's bar (or ABSENT), extra.
s6_extract() {
  local out
  out=$(python3 -I - "$@" <<'PY'
import datetime, hashlib, json, os, sys

lbl, src, path, iso, roc = sys.argv[1:6]

def emit(value, extra=""):
    print(value + "\t" + extra)

if not os.path.exists(path):
    emit("NO_FILE")
    sys.exit(0)
raw = open(path, "rb").read()
try:
    d = json.loads(raw.decode("utf-8-sig"))
except Exception as e:
    emit("NOT_JSON", "%s bytes=%d" % (type(e).__name__, len(raw)))
    sys.exit(0)

try:
    if src.startswith("twse_stock_day"):
        rows = d.get("data") or []
        hit = [r for r in rows if r and str(r[0]).strip() == roc]
        emit("|".join(hit[0]) if hit else "ABSENT",
             "stat=%s rows=%d last=%s" % (d.get("stat"), len(rows), rows[-1][0] if rows else "-"))
    elif src.startswith("tpex_stock"):
        tables = d.get("tables") or []
        rows = (tables[0].get("data") if tables and isinstance(tables[0], dict) else None) or []
        hit = [r for r in rows if r and str(r[0]).replace(" ", "") == roc]
        emit("|".join(hit[0]) if hit else "ABSENT",
             "stat=%s rows=%d last=%s" % (d.get("stat"), len(rows), rows[-1][0] if rows else "-"))
    elif src.startswith("fm_"):
        rows = d.get("data") or []
        hit = [r for r in rows if r.get("date") == iso]
        keys = ("open", "max", "min", "close", "Trading_Volume")
        emit("|".join(str(hit[0].get(k)) for k in keys) if hit else "ABSENT",
             "status=%s rows=%d last=%s" % (d.get("status"), len(rows), rows[-1].get("date") if rows else "-"))
    elif src.startswith("yahoo_"):
        res = d["chart"]["result"][0]
        meta = res.get("meta") or {}
        ts = res.get("timestamp") or []
        q = res["indicators"]["quote"][0]
        off = int(meta.get("gmtoffset") or 0)
        utc = datetime.timezone.utc
        local = [datetime.datetime.fromtimestamp(t + off, utc).date().isoformat() for t in ts]
        rmt = meta.get("regularMarketTime")
        rmt_s = datetime.datetime.fromtimestamp(int(rmt), utc).isoformat() if rmt else "-"
        extra = "bars=%d last_local=%s regularMarketTime_utc=%s regularMarketPrice=%s" % (
            len(ts), local[-1] if local else "-", rmt_s, meta.get("regularMarketPrice"))
        if iso in local:
            i = local.index(iso)
            emit("|".join(str(q[k][i]) for k in ("open", "high", "low", "close", "volume")), extra)
        else:
            emit("ABSENT", extra)
    elif src.startswith("all_"):
        code = "2330" if "twse" in src else "6147"
        rows = d if isinstance(d, list) else []
        hit = [r for r in rows if isinstance(r, dict) and code in [str(v).strip() for v in r.values()]]
        emit(json.dumps(hit[0], ensure_ascii=False)[:300] if hit else "ABSENT",
             "rows=%d body_sha256=%s" % (len(rows), hashlib.sha256(raw).hexdigest()[:16]))
    else:
        emit("UNKNOWN_SRC", src)
except (KeyError, IndexError, TypeError, AttributeError) as e:
    emit("UNEXPECTED_SHAPE", type(e).__name__)
PY
)
  printf '%s\t%s\t%s\t%s\n' "$(TZ=Asia/Taipei date '+%F %T')" "$1" "$2" "$out" | tee -a "$PROBE_DIR/s6/bars_by_round.tsv"
}

# s6_snap <label> [all]: one same-day-bar round (6 requests; 8 with "all"). Run on a TRADING day only.
s6_snap() {
  local lbl="$1" with_all="${2:-}" d_iso roc ym tpm d7 p1 p2 n
  if [ "$(TZ=Asia/Taipei date +%u)" -ge 6 ]; then
    echo "STOP: it is Saturday/Sunday in Taipei; a same-day-bar round proves nothing. Run on a trading day."
    return 1
  fi
  d_iso="$(TZ=Asia/Taipei date +%F)"
  ym="$(TZ=Asia/Taipei date +%Y%m01)"
  tpm="$(TZ=Asia/Taipei date +%Y/%m/01)"
  roc="$(( $(TZ=Asia/Taipei date +%Y) - 1911 ))/$(TZ=Asia/Taipei date +%m/%d)"
  d7="$(python3 -I -c 'import datetime,sys; print(datetime.date.fromisoformat(sys.argv[1]) - datetime.timedelta(days=7))' "$d_iso")"
  # Same period1/period2 convention as app/data/providers/yfinance.py: start 00:00 UTC, end 00:00 UTC + 86400.
  read -r p1 p2 < <(python3 -I -c '
import datetime, sys
a = datetime.date.fromisoformat(sys.argv[1]); b = datetime.date.fromisoformat(sys.argv[2])
e = lambda d: int(datetime.datetime(d.year, d.month, d.day, tzinfo=datetime.timezone.utc).timestamp())
print(e(a), e(b) + 86400)' "$d7" "$d_iso")
  echo "== s6_snap $lbl | Taipei now: $(TZ=Asia/Taipei date '+%F %T %z') | target date: $d_iso (ROC $roc)"

  s6_clear "${lbl}_twse_2330"
  probe s6 "${lbl}_twse_2330" "https://www.twse.com.tw/exchangeReport/STOCK_DAY?response=json&date=${ym}&stockNo=2330"
  s6_extract "$lbl" twse_stock_day_2330 "$PROBE_DIR/s6/${lbl}_twse_2330.body" "$d_iso" "$roc"
  [ -e "$PROBE_DIR/.STOP" ] && { echo "STOP file present; round aborted."; return 1; }

  s6_clear "${lbl}_tpex_6147"
  probe s6 "${lbl}_tpex_6147" "https://www.tpex.org.tw/www/zh-tw/afterTrading/tradingStock?code=6147&date=${tpm}&id=&response=json"
  s6_extract "$lbl" tpex_stock_6147 "$PROBE_DIR/s6/${lbl}_tpex_6147.body" "$d_iso" "$roc"
  [ -e "$PROBE_DIR/.STOP" ] && { echo "STOP file present; round aborted."; return 1; }

  for n in 2330 6147; do
    s6_clear "${lbl}_fm_${n}"
    fm s6 "${lbl}_fm_${n}" TaiwanStockPrice data_id="$n" start_date="$d7" end_date="$d_iso"
    s6_extract "$lbl" "fm_price_${n}" "$PROBE_DIR/s6/${lbl}_fm_${n}.body" "$d_iso" "$roc"
    [ -e "$PROBE_DIR/.STOP" ] && { echo "STOP file present; round aborted."; return 1; }
  done

  # ^TWII is what production fetches from Yahoo for TW. 2330.TW is exploratory only (production does not use Yahoo for TW stocks).
  for n in "%5ETWII:yahoo_twii" "2330.TW:yahoo_2330tw"; do
    s6_clear "${lbl}_${n#*:}"
    probe s6 "${lbl}_${n#*:}" "https://query1.finance.yahoo.com/v8/finance/chart/${n%%:*}?period1=${p1}&period2=${p2}&interval=1d"
    s6_extract "$lbl" "${n#*:}" "$PROBE_DIR/s6/${lbl}_${n#*:}.body" "$d_iso" "$roc"
    [ -e "$PROBE_DIR/.STOP" ] && { echo "STOP file present; round aborted."; return 1; }
  done

  if [ "$with_all" = "all" ]; then
    # The two whole-market single-file snapshots. STOCK_DAY_ALL has no date field (ADR-0012 DE-1'): compare the row and the body hash.
    s6_clear "${lbl}_all_twse"
    probe s6 "${lbl}_all_twse" "https://openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL"
    s6_extract "$lbl" all_twse_2330 "$PROBE_DIR/s6/${lbl}_all_twse.body" "$d_iso" "$roc"
    [ -e "$PROBE_DIR/.STOP" ] && { echo "STOP file present; round aborted."; return 1; }
    s6_clear "${lbl}_all_tpex"
    probe s6 "${lbl}_all_tpex" "https://www.tpex.org.tw/openapi/v1/tpex_mainboard_daily_close_quotes"
    s6_extract "$lbl" all_tpex_6147 "$PROBE_DIR/s6/${lbl}_all_tpex.body" "$d_iso" "$roc"
  fi
}

# s6_compare: per (taipei date, source), list the same-day bar seen in each round and flag differences.
s6_compare() {
  python3 -I - "$PROBE_DIR/s6/bars_by_round.tsv" <<'PY'
import collections, sys
groups = collections.OrderedDict()
for line in open(sys.argv[1], encoding="utf-8"):
    p = line.rstrip("\n").split("\t")
    if len(p) < 4:
        continue
    ts, lbl, src, val = p[0], p[1], p[2], p[3]
    extra = p[4] if len(p) > 4 else ""
    groups.setdefault((ts[:10], src), []).append((ts[11:], lbl, val, extra))
BAD = ("ABSENT", "NO_FILE", "NOT_JSON", "UNEXPECTED_SHAPE", "UNKNOWN_SRC")
for (day, src), items in groups.items():
    print("== %s  %s" % (day, src))
    for ts, lbl, val, extra in items:
        print("   %s  %-8s %s" % (ts, lbl, val[:120]))
    present = {v for _, _, v, _ in items if v not in BAD}
    present_in = [lbl for _, lbl, v, _ in items if v not in BAD]
    absent_in = [lbl for _, lbl, v, _ in items if v == "ABSENT"]
    if len(present) > 1:
        print("   >> VALUES DIFFER across rounds (%d distinct)" % len(present))
    elif present and absent_in:
        print("   >> present in %s but ABSENT in %s (read the times: absent earlier = not published yet)" % (",".join(present_in), ",".join(absent_in)))
    elif present:
        print("   >> same value in every round that had it")
    else:
        print("   >> never present in any round")
    if src.startswith("all_"):
        shas = {e.split("body_sha256=")[-1] for _, _, _, e in items if "body_sha256=" in e}
        if len(shas) > 1:
            print("   >> whole-body sha256 DIFFERS across rounds (%d distinct)" % len(shas))
PY
}
EOF
```

### 6.3 各日線來源會不會回傳「當日、尚未定案」的 bar（Q-B7、F-2、F-3）

#### 6.3.1 先講【讀碼】：目前的程式在這件事上沒有任何防線

| 事實 | 位置 |
|---|---|
| TWSE／TPEx 轉接器只丟掉 `--` 無成交列；其餘列一律當成 bar，**不看日期是不是今天、也不看是否收盤** | `twse.py:151-166`；`tpex.py:286-313`；`_util.py:37-45` |
| FinMind 轉接器只用 `start <= bar.date <= end` 過濾 | `finmind.py:163-167` |
| yfinance 轉接器同樣只過濾 `start <= bar.date <= end`；**bar 日期取 UTC 日期**（`datetime.fromtimestamp(ts, UTC).date()`）；只有 OHLCV 任一為 null 才跳過 | `yfinance.py:360, 380-385` |
| 所有轉接器的 `as_of` 是**抓取當下的時鐘**，不是來源宣稱的資料時間；`PriceBar` 沒有「是否定案」欄位 | `twse.py:88,187`；`finmind.py:100,181`；`yfinance.py:160`；`interface.py:46-68` |
| 寫入快取前唯一的閘門是**幣別**（`_judge_bars`）；通過就 `put`（以 `(symbol, market, trade_date)` upsert，後寫者勝） | `service.py:334-353`；`cache.py:177-231` |
| 因為是 upsert，**同一日的暫定 bar 會在下次重抓時被覆蓋**；但是否會重抓，取決於 `judge()`：只要快取最後一根 bar 的日期 ≥ `expected_session`（15:00 後為今天），就判 `HAS_LATEST_SESSION` 而不重抓 | `freshness.py:130-169` |
| 排程的 `pit_snapshot_capture` 除了 17:30／19:30／21:30，**啟動時也立刻跑一次**（`next_run_time=started`），我 grep 到的 `capture_once`／`capture_pit_snapshot` 路徑沒有時段防護 | `scheduler.py:660-672` |
| 整市場快照的「交易日自證」做法：候選日期取台北當天，向 FinMind 查同一天某幾檔，**收盤與成交量完全相符**才認定；FinMind 當天查無資料或不符則整批 failed | `twse_snapshot.py:203-206, 316-350` |

【推論】（沒有實測，正是 6.3 要驗證的）：

1. 若某來源在盤中回傳「當日、進行中」的 bar，它會被原樣寫進 `price_bars_cache`，並且在 15:00 後被 `judge()` 視為「已含最新交易日」而**不再重抓**，暫定值可能留到下一個交易日。這是 ADR-0009 修訂（S3-1）當初擔心 `market_has_session` 的反方向風險。
2. 整市場快照的自證機制在「TWSE 與 FinMind 兩個來源都回傳同一份暫定值」時會通過，因為它只比對兩者相等，不判斷是否收盤。若兩者都不回傳盤中當日列，則自然擋下。
3. Yahoo 的日線在盤中通常含「進行中的當日 bar」，這是對該服務行為的一般認知，**本 repo 沒有實測紀錄**；`^TWII` 是 TW 市場唯一走 Yahoo 的序列（`services/index.py:303`），6.4 會說明它如何進入觀察日集合。

#### 6.3.3a 補充欄：VS-4 之後的當日 bar 是否已定案（F-7；2026-10-17 追加）

對應 `work/reviews/2026-10-17-ADR-0028修訂提案r3觀察日來源-tech-architect.md` 第五節第 2 點 (c) 與其 F-7：「§6.3 發現某個所用來源在 VS-4 之後仍回傳未定案的 bar。走 F-3，把 VS-4 升級成 (market, source) 鍵；已翻轉的 R4c 退回 LM-71＋LM-26，直到重新確認。」VS-4 以現行候選值 15:00（台北）計，尚未查證（§6.1）。

這一欄是上面 6.3.3 判讀矩陣的**補充欄**。為了不改動矩陣既有各列，補充欄以對照表放在矩陣之後（「矩陣列」＝6.3.3 表由上往下數的第 n 列）。每個來源、每個交易日各填一格，值只能是下面四種之一：**已定案**、**未定案（F-7 候選）**、**VS-4 當下尚無**、**無法判定**。

| 矩陣列 | 觀察 | 補充欄「VS-4 之後的當日 bar 是否已定案」怎麼填 |
|---|---|---|
| 1 | 盤中輪 `ABSENT`，晚間輪有值 | 不由此列決定；看 15:00 之後各輪（見下方腳本）。盤中不回傳不代表 15:00 之後已定案 |
| 2 | 盤中輪有值，且與晚間值不同 | 不由此列決定。盤中暫定值被晚間值覆蓋，只說明「盤中會暫定」（F-2）；F-7 只比較 15:00 之後的輪次 |
| 3 | 盤中輪有值，且與晚間值相同 | 同上；另標明該輪是否真在 09:05～13:25 之間 |
| 4 | `t1335` 與 `t2130` 不同 | 看 `t1505`：`t1505` 已等於 `t2130` → **已定案**（變動發生在 15:00 之前，F-7 不成立）；`t1505` 不等於 `t2130` → **未定案（F-7 候選）**；沒跑 `t1505` → **無法判定**，必須補跑 |
| 5 | `t1505` 才首次出現當日列 | **VS-4 當下尚無**：這是 F-3（15:00 假設失效），不是 F-7；仍記錄之後各輪是否一致 |
| 6 | 全市場快照 `body_sha256` 在盤中與晚間不同，但 2330 列相同 | 只比較 15:00 之後的輪次：sha 不同 → **未定案（F-7 候選）**（整份快照在 VS-4 之後仍在變動，影響市場 DB 的 ok run 是否最終）；相同 → **已定案** |
| 7 | Yahoo 輪的 `regularMarketTime_utc` 早於收盤時間，而當日列存在 | 只看 15:00 之後的輪次：若 `regularMarketTime_utc` 仍早於當日收盤（台北 13:30 ＝ 05:30 UTC）→ **未定案（F-7 候選）**；已不早於收盤且值與之後各輪相同 → **已定案**。此項只對 `^TWII` 與探索性的 `2330.TW` 有意義 |

### 6.5 結構上沒有漲跌幅限制的商品，與個股 claim 範圍（B-2）

風控條件：「data-engineer 查證個股 claim 的範圍內，有沒有結構上沒有漲跌幅限制的商品，例如槓桿／反向 ETF、國外成分 ETF（推論，未查證）。若有，要在 D_v 前二選一：事先登記排除，或另送 LM-63 變體。」

#### 6.5.1 【讀碼】個股 claim 的範圍如何被界定

| 事實 | 位置 |

2. 「持倉資料鏈」與「展望 claim」是兩條不同的鏈：槓桿／反向 ETF 可以出現在使用者的持倉估值裡，但不進個股展望的 PIT 視圖。LM-63 的範圍界定應以後者為準。**這個劃分是否成立，取決於 `E-SCOPE-TYPE` 的實作判準，歸 tech-architect／dev-lead 確認**。
3. 新上市前 5 日：由「σ60 至少 55 個有效報酬」（事先宣告 §2.1 `SIGMA_MIN_VALID`）與 `_seasoned` 的 60 個交易日，**個股／族群紀錄的觀察窗不會落在上市初期**。這是 tech-architect 在 B-2 的推論，我同意其邏輯，但「前 5 日無漲跌幅限制」這條規定本身要先查證（見 6.5.2）。

#### 6.6.2 【推論】（強烈建議 tech-architect 與 quant 先看這一段）

1. **除權息覆蓋在 D0 的 60 日窗內，結構上不太可能完整。** 事先宣告的 `E-ADJ-COVERAGE` 定義是「除權息同步記錄的涵蓋起點晚於窗起點，或覆蓋判定為 unknown」。涵蓋起點只會是「第一次 `dividend_announce` ok run」之後；暖身 CLI 只補 bars，不補除權息。所以：
   - 若排程在 D0 之前已常駐累積 ≥ 60 個交易日加 1 日以上，成員才可能是 known；
   - 否則 D0 當天、窗內絕大多數成員會是 unknown，被排除的權重合計很可能 > 10%，**族群輸出 `E-ADJ-COVERAGE`（fail-closed）**，σ_d 算不出來。
   - 這不是缺陷，是 fail-closed 的設計結果；但它直接決定「族群預測最早何時能開始累積」，值得 CEO 與 quant 在 C-4 凍結前知道。
2. 「暖身 80 日 bars」本身足夠；**阻礙來自除權息，不是日線**。
3. 暖身日線若是原始價（待 §3.3 驗證），則在窗內有除權息的成員，σ_d 的日報酬會在除息日含一個機械性的缺口；即使有因子，也要確認因子計算所用的前一日收盤與暖身價格口徑一致。若 FinMind 已是還原價，則會與 `AdjustedSeries` 的再還原重複還原，這會比沒有還原更糟。**這個口徑問題要在 σ_d 實作前由 quant 判讀**。
4. B1／B4 在 D0 之後最初 h（3 或 5）個交易日需要 D0 之前的 `listing`（S_{T−h}）。若 `listing` 的第一個 ok run 就是 D0 當天，這些日子的 B1／B4 沒有 PIT 成員集合可用。實際影響取決於事先宣告對這些樣本的處理（無效或沿用 D0），**不是我能決定的，列給 quant**。
