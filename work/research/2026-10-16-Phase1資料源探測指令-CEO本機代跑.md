## 0. 怎麼用（先讀）

### 0.1 一般守則（違反任一條請停手回報）

1. **只做唯讀 GET**。沒有 POST、沒有登入、沒有表單送出。
2. **限速**：每支請求之間 `sleep 6` 秒（`PROBE_SLEEP` 可調大，不要調小）。全部跑完約 70 次請求，單一指令區塊對同一網域通常不超過 15 次。
3. **不得大量下載**：每支指令都是單檔、單月或單檔個股；不要自行改成全市場逐檔迴圈、不要改長日期範圍。
4. **遇到 HTTP 403／429／503 就停**：helper 會自動建立 `$PROBE_DIR/.STOP`，之後所有 probe 會拒絕執行。不要重試、不要換 IP，等 15 分鐘以上、把狀況回報後再說。
5. **不跟隨轉址**（不加 `-L`）。看到 3xx 把 `redirect_url` 欄位回報即可。
6. **不要用 `set -x`、`curl -v`、`--trace`**：會把展開後的 token 印到畫面。
7. 需要金鑰的只有 FinMind：由 CEO 自行在本機終端機設定環境變數 `FINMIND_API_TOKEN`，**不要把它貼回對話、不要寫進任何檔案**。指令裡一律寫 `$FINMIND_API_TOKEN`。
   設定方式（先輸入 `bash` 進入 bash；貼上時畫面不會顯示）：

   ```bash
   # Read the token silently into this terminal session only; never write it to a file.
   read -rs FINMIND_API_TOKEN; export FINMIND_API_TOKEN
   ```

8. 本文件所有輸出只存在本機資料夾 `~/stock-desk-probe-2026-10-16/`，**不要放進 repo 的 `apps/stock-desk/backend/data/`**。

### 0.2 建立資料夾與 helper（每個新終端機視窗先確認 `$PROBE_DIR` 有設定）

```bash
# Create the probe folder and write the helper library (idempotent).
export PROBE_DIR="$HOME/stock-desk-probe-2026-10-16"
mkdir -p "$PROBE_DIR"/{common,t107,t108,t109,t110}

cat > "$PROBE_DIR/probe_lib.sh" <<'EOF'
# probe_lib.sh -- read-only GET helpers for the Phase 1 data-source probes.
# Rules baked in: GET only, fixed sleep between requests, no redirects followed,
# no secrets written to disk, hard stop on 403/429/503.
PROBE_DIR="${PROBE_DIR:-$HOME/stock-desk-probe-2026-10-16}"
PROBE_UA="stock-desk-probe/1.0 (personal research, read-only, low rate)"
PROBE_SLEEP="${PROBE_SLEEP:-6}"
PROBE_LAST_CODE=""

# probe <subdir> <name> <url> [extra curl args...]
probe() {
  local sub="$1" name="$2" url="$3"
  shift 3
  mkdir -p "$PROBE_DIR/$sub"
  if [ -e "$PROBE_DIR/.STOP" ]; then
    echo "SKIP $sub/$name: $PROBE_DIR/.STOP exists (block or rate limit seen earlier)."
    echo "     Wait at least 15 minutes, then: rm \"$PROBE_DIR/.STOP\""
    PROBE_LAST_CODE="skipped"
    return 1
  fi
  local meta code
  meta=$(curl -sS --connect-timeout 10 --max-time 45 -A "$PROBE_UA" \
    -D "$PROBE_DIR/$sub/$name.headers.txt" -o "$PROBE_DIR/$sub/$name.body" \
    -w '%{http_code}\t%{size_download}\t%{time_total}\t%{content_type}\t%{redirect_url}' \
    "$@" "$url") || meta=$(printf 'curl_error\t0\t0\t-\t-')
  code="${meta%%$'\t'*}"
  PROBE_LAST_CODE="$code"
  printf '%s\t%s\t%s\t%s\n' "$(TZ=Asia/Taipei date '+%F %T %z')" "$sub/$name" "$meta" "$url" \
    | tee -a "$PROBE_DIR/_index.tsv"
  case "$code" in
    403|429|503)
      touch "$PROBE_DIR/.STOP"
      echo "STOP: HTTP $code received. All further probes are disabled. Do NOT retry; report back." ;;
  esac
  sleep "$PROBE_SLEEP"
}

# probe_try <subdir> <name> <url1> <url2>: url2 is requested only if url1 is not HTTP 200 JSON
probe_try() {
  probe "$1" "$2" "$3"
  local first
  first=$(head -c 1 "$PROBE_DIR/$1/$2.body" 2>/dev/null)
  if [ "$PROBE_LAST_CODE" != "200" ] || [ "$first" = "<" ] || [ -z "$first" ]; then
    echo "  -> primary URL not usable (code=$PROBE_LAST_CODE); trying alternate URL once"
    probe "$1" "$2.alt" "$4"
  fi
}

# fm <subdir> <name> <dataset> [key=value ...]: FinMind v4 data GET; token comes from the environment only
fm() {
  if [ -z "${FINMIND_API_TOKEN:-}" ]; then
    echo "SKIP fm $2: FINMIND_API_TOKEN is not set in this shell"
    return 1
  fi
  local sub="$1" name="$2" ds="$3"
  shift 3
  local args=(-G --data-urlencode "dataset=$ds") kv
  for kv in "$@"; do args+=(--data-urlencode "$kv"); done
  if [ "${FM_TOKEN_MODE:-header}" = "param" ]; then
    args+=(--data-urlencode "token=${FINMIND_API_TOKEN}")
    probe "$sub" "$name" "https://api.finmindtrade.com/api/v4/data" "${args[@]}"
  else
    probe "$sub" "$name" "https://api.finmindtrade.com/api/v4/data" \
      -H "Authorization: Bearer ${FINMIND_API_TOKEN}" "${args[@]}"
  fi
}

# jsonshape <subdir/name>: print top-level shape of a saved JSON body (keys, list lengths, first/last element)
jsonshape() {
  python3 -I - "$PROBE_DIR/$1.body" <<'PY'
import json, sys
p = sys.argv[1]
try:
    raw = open(p, 'rb').read()
except OSError as e:
    print('NO_FILE', e)
    sys.exit(0)
try:
    d = json.loads(raw.decode('utf-8-sig'))
except Exception as e:
    print('NOT_JSON', type(e).__name__, '| first 120 bytes:', raw[:120])
    sys.exit(0)
def short(x, n=300):
    s = json.dumps(x, ensure_ascii=False)
    return s if len(s) <= n else s[:n] + '...'
if isinstance(d, list):
    print('list len=%d' % len(d))
    if d:
        print('first:', short(d[0]))
        print('last :', short(d[-1]))
elif isinstance(d, dict):
    print('dict keys:', list(d.keys())[:20])
    for k, v in d.items():
        if isinstance(v, list):
            print('  [%s] list len=%d' % (k, len(v)))
            if v:
                print('    first:', short(v[0]))
                print('    last :', short(v[-1]))
        elif isinstance(v, dict):
            print('  [%s] dict keys=%s' % (k, list(v.keys())[:15]))
        else:
            print('  [%s] = %s' % (k, short(v, 120)))
PY
}

# hdrs <subdir/name>: print only the time-related response headers
hdrs() {
  grep -iE '^(HTTP/|date:|last-modified:|age:|etag:|cache-control:|expires:|content-type:|x-ratelimit|retry-after)' \
    "$PROBE_DIR/$1.headers.txt" | tr -d '\r'
}

# timing_run <label>: one polling round for "when is today's close published" (3 GET requests)
timing_run() {
  local lbl="$1" ym roc tp_month f
  ym="$(TZ=Asia/Taipei date +%Y%m01)"
  tp_month="$(TZ=Asia/Taipei date +%Y/%m/01)"
  roc="$(( $(TZ=Asia/Taipei date +%Y) - 1911 ))/$(TZ=Asia/Taipei date +%m/%d)"
  echo "== timing_run $lbl | Taipei now: $(TZ=Asia/Taipei date '+%F %T %z') | looking for ROC date: $roc"
  probe t107 "timing_${lbl}_twse_stock_day_2330" \
    "https://www.twse.com.tw/exchangeReport/STOCK_DAY?response=json&date=${ym}&stockNo=2330"
  probe t107 "timing_${lbl}_twse_fmtqik" \
    "https://www.twse.com.tw/exchangeReport/FMTQIK?response=json&date=${ym}"
  probe t107 "timing_${lbl}_tpex_6147" \
    "https://www.tpex.org.tw/www/zh-tw/afterTrading/tradingStock?code=6147&date=${tp_month}&id=&response=json"
  for f in twse_stock_day_2330 twse_fmtqik tpex_6147; do
    printf '%s\t%s\t%s\t' "$(TZ=Asia/Taipei date '+%F %T')" "$lbl" "$f"
    if grep -q "$roc" "$PROBE_DIR/t107/timing_${lbl}_${f}.body" 2>/dev/null; then
      echo "TODAY_ROW_PRESENT"
    else
      echo "today_row_absent"
    fi
  done | tee -a "$PROBE_DIR/t107/timing_summary.tsv"
}
EOF

# Syntax check only (does not run any request).
bash -n "$PROBE_DIR/probe_lib.sh" && echo "probe_lib.sh syntax OK"
```

helper 說明（給判讀用）：

- 每次 `probe` 會在終端機印一行、同時附加到 `$PROBE_DIR/_index.tsv`，欄位依序為：台北時間、`子資料夾/名稱`、`http_code`、`size_download`、`time_total`、`content_type`、`redirect_url`、URL。**這個 `_index.tsv` 不含任何金鑰（FinMind 走標頭，不進 URL），可整份貼回。**
- 每個回應存成 `名稱.body`（本體）與 `名稱.headers.txt`（回應標頭），原檔留在本機。
- `probe_try` 用在「我不確定主站或新站哪個路徑還活著」的地方：第一個 URL 不是 HTTP 200 JSON 才會打第二個。
- `fm` 預設用 `Authorization: Bearer` 標頭帶 token（避免 token 進 URL 與 `_index.tsv`）。若 FinMind 回 `status` 非 200 且訊息指向 token 無效，改用 `export FM_TOKEN_MODE=param` 再重跑該支（現行 adapter 用的是 query 參數，見 `app/data/providers/finmind.py`）；此模式下 token 仍不會寫進 `_index.tsv`。**請把「標頭模式是否可用」寫進回貼。**

```bash

# 1) Catalogue files (Swagger/OpenAPI spec) of both exchanges. 404 on either path is an acceptable outcome; report it.
probe common twse_openapi_swagger "https://openapi.twse.com.tw/v1/swagger.json"

probe common tpex_openapi_home "https://www.tpex.org.tw/openapi/"

# 3) List "path <TAB> summary" from a saved swagger file (jq if available, python3 -I as fallback).
list_paths() {
  if command -v jq >/dev/null 2>&1; then
    jq -r '.paths | to_entries[] | "\(.key)\t\(.value.get.summary // "")"' "$1"
  else
    python3 -I -c '
import json, sys
d = json.load(open(sys.argv[1], encoding="utf-8"))
for p, v in sorted(d["paths"].items()):
    print(p + "\t" + (v.get("get") or {}).get("summary", ""))
' "$1"
  fi
}
list_paths "$PROBE_DIR/common/twse_openapi_swagger.body" > "$PROBE_DIR/common/twse_paths.tsv"
list_paths "$PROBE_DIR/common/tpex_openapi_swagger.body" > "$PROBE_DIR/common/tpex_paths.tsv"

# 5) License / terms evidence: the 'info' block of each spec plus any terms-like links on the landing pages.
for f in twse_openapi_swagger tpex_openapi_swagger; do
  echo "--- $f info ---"
  jq -c '.info' "$PROBE_DIR/common/$f.body" 2>/dev/null || head -c 600 "$PROBE_DIR/common/$f.body"

for f in twse_openapi_home tpex_openapi_home; do
```

### 1.2 要驗證的問題

1. 端點：哪個路徑真的回 JSON？HTTP 狀態？回應 `Content-Type` 與編碼？
2. 年份範圍：2024、2025、2026、2027 各年是否有資料？**2027 在 2026-10 是否已公布**（決定 `valid_until_session` 能往前算多遠）。
3. 欄位：有無日期、名稱（休市原因）、說明、是否含「補班」「結算日」「最後交易日」等；日期格式是西元還是民國（例如 `1150101`）。
4. 臨時休市：2024-10 的 `holidaySchedule` 與 `FMTQIK`（單月成交日清單）是否一致？不一致處即「表上沒有、但實際沒開市」的日子，直接回答 AC-B5b-2（颱風假）能否只靠官方表。
5. 授權條款與額度：OpenAPI／官網有無 rate limit 說明、使用條款、是否允許快取與衍生顯示。
6. 時間欄位與時區：回應標頭 `Date`（GMT）與台北時間的換算；回應本體內有無更新時間。
7. point-in-time：此表是否會被事後更正？沒有版本時間戳的話，只能由我們自己存快照（抓取時間 + sha256）。本次先取一次快照，約一個月後建議重抓一次比對（後續動作，不在本次範圍）。

### 1.3 指令一：休市日表與交叉驗證（約 12 次請求）
