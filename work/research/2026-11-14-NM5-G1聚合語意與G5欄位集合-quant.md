## G1 規則聚合語意

**更正前一份缺口清單**：附錄 B 只有前三票會取 −1、0、+1，第 4 票是「是否高波動」的二元狀態，不加總。所以窮舉測試是 **27 種投票組合 × 2 種波動狀態 = 54 例**，不是 81 × 2。

**1. 聚合採 ADR-0025 D-2.3，只外加一步「減半」**（A1～A5 依序執行）

| 步 | 語意 | 建議放 |
|---|---|---|
| A1 完整度 | 可評估比例 ＝ 可評估的條件數 ÷ 條件總數。條件總數含每條規則，也含減半條件。比例 < `MIN_COMPLETENESS` 時輸出 `insufficient`，並依 §5.2 列出缺項。「可評估」指條件讀到的每個欄位都有值，而且是有限值 | 閾值放 YAML；演算法放 engine |
| A2 淨權重 | W ＝ Σ 命中的偏多規則權重 − Σ 命中的偏空規則權重。震盪規則不計權重 | engine |
| A3 減半（附錄 B 第 4 票） | 減半條件成立時，W ← trunc(W ÷ 2)，向 0 取整 | 條件與 1.5 放 YAML（`damping`）；運算放 engine |
| A4 判定 | \|W\| < θ_h 時判 `range`；W ≥ θ_h 判 `bullish`；W ≤ −θ_h 判 `bearish` | θ_h 放 YAML |
| A5 `range_basis` | 判 `range` 時：有震盪規則命中，**或減半條件成立**，記 `range_evidence`；否則記 `conflicting_evidence` | engine〔待確認〕 |

- **為什麼要外加 A3**：`OutlookRuleSet` 目前只有 `version`、`rules`（`extra=forbid`）。建議加 `aggregation: {theta, min_completeness, damping: {condition, factor: 0.5, rounding: toward_zero} | null}`。這三個值是規則參數，應該進 `rules_logic_sha256`。演算法本身寫在 engine，由 `code_digest` 鎖住。
  - 備案：減半寫死在 engine。不建議，因為 1.5 這個值會落在規則雜湊之外。
- **同票順序**：聚合由總和與 θ 決定，不會有同票，所以不需要順序。`MAJORITY_TIE_ORDER` 只用在 B2 基準，放 dirdef（見 G5）。
- **精確運算**：W 以 `fractions.Fraction` 累加，比較也用 Fraction，跨平台逐位相同（ADR-0030 D-5 第 3 點）。
- **A5 的讀法**：ADR-0025 只寫「有 range 規則命中時為前者」，沒有考慮減半。如果照字面，三票同向但被減半的情況會記成 `conflicting_evidence`（互相抵銷），這不符事實。所以我把「減半條件成立」也算作震盪證據〔待確認〕。
- **必須揭露的算術事實**：權重都是 1、θ＝2 時 |W| ≤ 3，減半後 |W| ≤ 1，所以**只要高波動條件成立，結果一律是震盪**。規則字面要寫「改判震盪」，不能寫成「訊號減弱」，這交風控在語意審時看。

**2. 附錄 B 的編碼**（欄位名暫定，公式屬 G2）：每一票拆成偏多、偏空、中性三條規則，權重都是 1，中性那條的方向是 `range`。這樣附錄 B「投 0 → `range_evidence`」就和 ADR-0025 的 range 規則對上。

| 票 | 偏多（bullish） | 偏空（bearish） | 中性（range） |
|---|---|---|---|
| 趨勢 | close gt ma20 且 ma20 gt ma60 | close lt ma20 且 ma20 lt ma60 | (close lte ma20 或 ma20 lte ma60) 且 (close gte ma20 或 ma20 gte ma60) |
| 動能 | z20 gt 0.5 | z20 lt −0.5 | z20 gte −0.5 且 z20 lte 0.5 |
| 反轉 | zh lt −1.5 | zh gt 1.5 | zh gte −1.5 且 zh lte 1.5 |

- `damping.condition`：`vol_ratio_20_120 gt 1.5`。`theta: 2`，`min_completeness: 1.0`。h3、h5 兩檔只差 `zh` 的 h。
- 現行 DSL 都表達得了（只用 `all`、`any` 與 gt／lt／gte／lte）。每一票恰好命中三條中的一條，這一點列為測試性質。

**3. 佔位規則**（只用於 harness，不登記；兩組都用欄位 `logret_h` ＝ ln(P(T)/P(T−h))，**必須和 B8 呼叫同一個函式**，K-6）

- **P-0（＝B6）**：一條 range 規則，條件為 `any[logret_h gte 0, logret_h lt 0]`（有值就恆真）；θ＝2，不設減半。W 恆為 0，所以恆判 `range`、記 `range_evidence`。
- **P-1（＝B8）**：三條規則：`logret_h gt 0` 判偏多、`lt 0` 判偏空、`eq 0` 判震盪；θ＝1，不設減半。W ∈ {−1, 0, 1}，逐筆等於 sign。
- 兩組需要的根數（h＋1）都少於 σ 需要的 61 根，所以除了 σ 本身判證據不足的那幾筆，不會多出證據不足。逐筆相等的斷言因此只在「非證據不足」的紀錄上成立，證據不足的情況用合成 fixture 測（D-7 第 4 點）。

**4. 參考實作（虛擬碼）**
```
def aggregate(rs, fields):
    conds = [r.condition for r in rs.rules] + ([rs.aggregation.damping.condition] if rs.aggregation.damping else [])
    ok = [evaluable(c, fields) for c in conds]          # every referenced field present and finite
    if Fraction(sum(ok), len(ok)) < Fraction(rs.aggregation.min_completeness):
        return Insufficient(missing=missing_items(conds, fields))
    hit = {r.id: holds(r.condition, fields) for r in rs.rules}
    w = sum(sign(r.direction) * Fraction(r.weight) for r in rs.rules if hit[r.id])  # range rules: sign 0
    damped = rs.aggregation.damping is not None and holds(rs.aggregation.damping.condition, fields)
    if damped:
        w = Fraction(math.trunc(w / 2))                  # halve, round toward zero
    theta = Fraction(rs.aggregation.theta)
    if w >= theta: return Label("bullish")
    if w <= -theta: return Label("bearish")
    any_range_hit = any(hit[r.id] for r in rs.rules if r.direction == "range")
    return Label("range", range_basis="range_evidence" if (any_range_hit or damped) else "conflicting_evidence")
```
