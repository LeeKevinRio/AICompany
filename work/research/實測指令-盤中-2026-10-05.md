## 事前 0：請先幫我看三個網頁（雲端環境連不到證交所，只有您的電腦能看）

風控要求在正式採用 MIS 前查證「證交所條款有沒有限制程式自動抓取」。請用瀏覽器打開下面三個網址，
把看到的內容複製貼給我（或截圖），不必判讀：

1. `https://mis.twse.com.tw/` — 頁首顯示的網站中文全名、頁尾的「免責聲明／使用條款」連結內容。
2. `https://www.twse.com.tw/` — 頁尾「網站使用條款」「免責聲明」「資訊使用／資訊授權」相關頁面的全文。
3. `https://openapi.twse.com.tw/` — 頁面上列出的 API 清單（看有沒有「盤中」「即時」「delay」字樣的項目）。

**若條款明文禁止程式化存取，請先不要跑下面的實測，告訴我即可，由您裁定是否改用其他來源。**

| # | 時間（台北） | 指令（在 `apps\stock-desk\backend` 執行） | 目的 |
| --- | --- | --- | --- |
| 1 | 08:30–08:55 | `uv run python ..\scripts\verify_intraday_quotes.py --phase pre-open --skip-rate-probe` | 開盤前 MIS 的回應樣態（有沒有 cookie、試撮值） |
| 2 | 09:30–11:00 之間任一時刻 | `uv run python ..\scripts\verify_intraday_quotes.py --phase mid --symbols 2330,5483,0050,00631L,<冷門股代號>` | 正常盤中：延遲、限流、欄位；**請自選一檔日成交量很小（約 100 張以下）的個股**代入（只填代號，不要保留角括號），用來看「久未成交」的樣態；上櫃股請寫 `otc:代號`。**只有這一次做限流探測**，決定 P-2 |

> 帶 `--skip-rate-probe` 的執行不做限流探測；限流探測一天只需一次（第 2 次），避免重複打太多次。
