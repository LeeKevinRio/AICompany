# 警示 400 日窗與建議卡 540 日窗差異——分析（dev-lead，2026-10-04）

> 主會話轉錄；只讀碼與 scratchpad 實測（`build_demo_bars` 記憶體資料，不碰 `backend/data/*.db`、不連網）；腳本 `scratchpad/win.py`（不在 repo）。

## 結論
- 差異確實存在，且**查不到任何刻意設計紀錄**。400（`app/alerts/snapshot.py` L39 `lookback_days: int = 400`）與 540（`app/api/signals.py` L40–L42 `DEFAULT_LOOKBACK_DAYS`，供 advice／bars／portfolio 共用）同在 commit `f4f7baa`（2026-07-26）進入；訊息只交代 540「K 線與 MA 疊圖 x 軸對齊」，未提 400；無任何 ADR 定義這兩個窗長（ADR-0012 C-13 只管 scheduler refresh 常數；ADR-0018 把 540 當既有事實）。
- `snapshot.py` L3–L5 docstring 寫警示「observe the same numbers the `/api/signals` and `/api/advice` endpoints show」，與 L39 實際 400 不一致。`app/demo/seed.py` L187–L193 事後承認差異並把示範警示門檻校準在 400 窗（遷就，非設計理由）。無測試釘住 400。
- **建議統一為 540**：屬 bug 修正、對齊程式碼已寫明的意圖；判斷不需新 ADR，待 tech-architect 確認。

## 受窗長影響的欄位
- 實質受影響（整窗計算，`app/signals/risk.py`）：`drawdown.current`（L262–L311）、`drawdown.max_drawdown`、`volatility.annualized`（L225–L260）。
- 實質不受影響：`ma5／20／60`、`bollinger.*`、`volume_z`（rolling，差約 1e-12）；`rsi14`、`atr14`（Wilder 初始值影響衰減至約 2e-9）；`macd.*`（約 1e-8）；`kd.*`（0）。
- 單向性：400 窗為 540 窗後段子集（結尾同日），故 `current_400 ≥ current_540`、`max_dd_400 ≥ max_dd_540`（回撤較淺）。`lt` 型規則只會「卡片命中、警示沒響」；`gt` 型相反。差異條件：最高收盤或最深回撤起點落在 (t−540, t−400]。
- `beta.value`：advice 與 alerts 皆未傳 benchmark（兩邊 None 一致），但 `/api/signals` 有傳——另一不一致，另案。

## 實測
A. demo 2026-10-02：2330 `max_drawdown` 400 窗 −0.1488 vs 540 窗 −0.2480（**跨 −20%**）；`current` 兩窗相同 −0.0785；00631L `volatility` 0.3812 vs 0.4010。技術指標差異 ≤ 2.6e-8。
B. demo 逐日 134 個評估日：2330 `max_dd` 不同 95 天、`mdd<-0.2` 命中不一致 36 天；`current` 跨門檻不一致 0 天（demo 高點皆在近期）。
C. 構造序列（舊高落在約 450 日前）：400 窗 `current=-0.1356`（不命中）vs 540 窗 `current=-0.2400`（命中 `drawdown_protection`）——同標的同日差 10.4 個百分點；警示訊息「最新收盤價相對區間最高收盤價的回撤 目前為 -0.1356」未標區間，使用者看不出分母不同。

## 選項
1. **統一為 540（建議）**：`build_snapshot` 預設改用共用常數；把 `DEFAULT_LOOKBACK_DAYS` 從 `app/api/signals.py` 移到非 API 層（如 `app/signals/`）再由端點 re-export，避免 `app.alerts` 反向 import `app.api`；補不變式測試（snapshot 的 `load_bars` start＝advice 的 start）。代價：無警示延遲（400 窗反而提早「忘記」舊高、提早解除）；每 tick 每檔多約 100 根 O(n)；僅被警示盯的標的首次抓取 14→18 次月請求（一次性）；**既有警示命中行為一次性變化**（`drawdown.*` `lt` 規則只會多響、`gt` 少響、`volatility` 兩向）須寫 release note 並知會風控；`seed.py` 註解過時須更新；`test_seeded_alert_rules_actually_fire` 需實跑確認。
2. 統一為 400（不建議）：牽動 signals／bars／portfolio、1.1.0 重審、ADR-0018 門檻惡化、quant L-6 重做。
3. 保留但揭露（不修 bug）：警示訊息標「近 400 日區間」需走風控；使用者仍見同欄位兩數字；警示永遠比卡片晚一步命中回撤；且須修 docstring 不實陳述。
