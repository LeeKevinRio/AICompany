# tech-architect 釐清全文（2026-10-07，HEAD c16eeee 唯讀讀碼；coordinator 原文轉錄）

## 本次結論
E1 不是測試造假，也不是 lot 層與 position 層的差別。原因是 `/api/advice` 這條正式路徑上，**engine 用 signals 的 ATR 回填，把 book 層已經撤下的 ATR 又放回來**。

- dev-lead 的前提測試只證明了 book 層，沒有證明端到端。
- 所以 ADR-0022「D-d1 更正註記」的前提（幣別混雜時第 4 條為 not_evaluable）**在 HEAD c16eeee 的 `/api/advice` 不成立**。
- coordinator 補充的 4 點我都讀碼驗證過，全部屬實。第 4 點（美股匯率不可用）確認是正式路徑，而且比 E1 更嚴重。
- 處置：採 qa-e2e 的選項 (1)，修回填（性質屬 (c)，既有缺陷）。D-d1 字面暫不退回「方向不定」，理由見「矛盾解析」，但要風控確認。

## 事實（檔案行號，路徑都在 `/home/user/AICompany/apps/stock-desk/backend/` 下）

1. **第 4 條的計算**（`app/advice/limits.py:1176-1204`）
   - 只要 `ctx.atr is None` 就回 not_evaluable（L1178-1179）。卡上算得出值，代表評估當下 atr 不是 None。
   - 停損距離 ＝ `atr_stop_multiple × ctx.atr × ctx.fx_to_twd`（L1185），沒有用到 close。
   - 股數來自 `held_shares()`（L817-824）。有 `quantity` 就直接用 `quantity`，所以 close 是 None 也照算。
2. **book 層撤下 close／atr**（`app/advice/book.py`）
   - L1093-1105：一檔標的的批次橫跨多種幣別時，`rate=None`。
   - L1124／L1129：close 與 atr 一起設為 None。
   - L1128：`fx_to_twd` 放占位值 1.0。註解原意是「close 是 None 時這個 1.0 永遠不會被套用」。
   - L1097：「價格類上限不計算」是 **inline 字串，不是具名常數**。我在 code 裡沒看到它的風控核可註記。
3. **engine 回填**（`app/advice/engine.py:318-323`）
   - `build_advice` 在 `portfolio.atr is None and context["atr14.last"] is not None` 時，用 signals 的 ATR 做 `model_copy`。
   - L354 再拿回填後的 context 跑 `evaluate_limits`。

   - L180：signals 由 `load_bars` 算出，不受估值器影響。
   - L241：API 傾印的 `portfolio_context` 是回填**前**的 `book.context`，所以 `atr` 顯示 null，但卡上實際用的是回填值。

6. **0.0079 怎麼來**：2.0 ×（2330 TW 日線的 ATR14，單位 TWD）× 1.0（占位值）× 1000 ÷ 總資產。
   - 1000 股只算已估值的 TWD 批次；USD 那 100 股被 `_position_rollup` 跳過（book.py:485-493）。
   - coordinator 以總資產 4,437,500 代算得 0.79%，推得 ATR 約 17.5，與第 1 條 20.70%（每股約 919）換算出的 ATR／價格約 1.9% 合理。
   - 原始 JSON 不在 repo 內，ATR 實際值我沒有獨立覆核。
7. **dev-lead 的前提測試**（`tests/test_adr0022_sector_unvalued.py:1287-1322`）

## 矛盾解析

- **前提**：「混雜時第 4 條為 not_evaluable」只在 book 層成立，端到端被 engine 回填破壞，所以現狀**不成立**。
- **D-d1 的「第 4 條偏低」在回填狀態下仍為真**：
  - E1（TW 日線，占位 1.0 剛好等於真實匯率 1）：observed＝m·ATR·q_v/E，就是原本的下限不等式，E ≥ A 時成立。
  - 美股兩邊都斷匯率：q_v＝0，observed＝0，不可能高於真值。
  - 一般情形：只要真實匯率 r ≥ 1（TWD＝1、USD 約 31），占位 1.0 只會讓結果偏低，不會偏高。
  - 但這是**我新提出的論證，不是風控當初審過的前提**，必須送風控裁定。
- **卡片自相矛盾是既有缺陷**，與 D-d 無關：E1 的「價格類上限不計算」、美股的「不以 1.0 匯率代入」，都和第 4 條實際 passed 衝突。這已經是**面向使用者的不實陳述**，而且在正式路徑上可達。
