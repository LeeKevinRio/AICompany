## 改寫稿（取代上面整段）

````
### 0.1 啟動需要的工具（git、uv、Node.js／npm）

用 `apps/stock-desk/dev-up.bat` 啟動時，會先檢查電腦上有沒有三樣工具：
git、uv、npm（npm 隨 Node.js 一起提供）。

缺少其中一樣時，畫面會出現以 `[MISSING]` 開頭的英文行。例如缺 git 時：

```
[MISSING] git was not found. Do not install or update anything yourself.
Tell the coordinator.
```

缺 uv 或 npm 時，第一行的工具名稱不同，其餘相同。同時缺兩樣以上時，會有
好幾行 `[MISSING]`，最後才是一行 `Tell the coordinator.`。

看到這些行時：

- 不要自己安裝、更新或移除任何程式。
- 把 `[MISSING]` 那一行（或整個畫面的截圖）告訴 coordinator。
- 要裝什麼、裝哪個版本，由 coordinator 告訴你。
- 裝好之後要不要再執行 `dev-up.bat`、什麼時候執行，由 coordinator 決定。

這些行表示還沒更新程式，也還沒啟動 stock-desk。

````
