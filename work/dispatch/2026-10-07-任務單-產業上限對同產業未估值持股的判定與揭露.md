## 問題
- 決策卡單一標的產業佔比上限（`app/advice/limits.py:868-895`）在有同產業未估值持股 x 時計算 (S−x)/(E−x)，比真值 S/E 小，可能**錯誤通過**（此上限擋「加碼」，危險方向）。
- 同一張卡的 context notes（`UNVALUED_POSITIONS_NOTE`，`app/advice/book_limits.py:105-120`）卻寫「比率會因此偏高」，等於在可能偏低的通過判定旁宣稱比率保守。
- `/api/portfolio/limits` 已有 `SECTOR_UNVALUED_EXCLUSION_SUFFIX`（2026-08-09 風控核可）揭露偏低；決策卡與警示路徑沒有。
- 既存問題，F-1 修前亦存在（總曝險會錯誤通過、產業佔比同樣偏低且無揭露）；F-1 修後總曝險改 not_evaluable 為淨改善，故不擋 F-1。

## 底線（風控）
只要有未估值持股屬於（或可能屬於）該產業，決策卡與警示的產業上限**不得在附著「偏高」宣稱的情況下回報 passed**。
- 傾向：比照總曝險前例，已知同產業時改 not_evaluable；產業未知時至少加上與 `SECTOR_UNVALUED_EXCLUSION_SUFFIX` 同義的揭露。
- 「比率會因此偏高」本身收窄適用範圍，creative-lead 起草三版一併送審。

### 資料與分類
- `SummaryPosition.sector` 取自持倉紀錄，未估值持股亦帶 sector／instrument_type／market；`book.py` `_sector_rollup` 只加總 ok 部位，`PortfolioContext` 無欄位帶出 → 新增欄位（同產業筆數、產業未知筆數）。
- 分類（對卡片產業 X）：**same**＝與卡片同一標的或 `u.sector == X`；**unknown**＝`u.sector is None`（台股未填／ETF／非台股三子類分列，供風控決定是否排除）；**other**＝有值且 ≠ X。
- 數學方向：只有 other → 算出值偏高（保守，「偏高」屬實）；只有 same → 算出值為下限，passed 不可靠、violated 必成立；same＋other／unknown 或只有 unknown → 方向不定，passed 不可靠。
- 總曝險前例（`_check_gross_exposure` 一律 not_evaluable）不照抄；**附帶發現**：第 3 條帳本不完整但已估值部分已超標時回 not_evaluable 不擋加碼，另列管。

### Decision（ADR 草案要點）
1. `build_book_context` 做一次分類，放進 `PortfolioContext` 新欄位；book.py 仍純函式（ADR-0005 決策 1／F-1）。
2. `_check_sector_weight`：same>0 → ≥ 上限 violated＋W2，否則 not_evaluable＋W1；same=0 且 unknown>0 → violated 不變、passed 附 W3；皆 0 → 逐字不變。
3. `notional_caps`：same 或 unknown >0 不放第 2 條。
4. 新欄位未設定退路：`book_fully_valued is True` 視無重疊，否則視「產業未知」；不猜「同產業」。
5. 「比率會因此偏高」依分支條件表收窄。

### Consequences
三路徑一致；永不以可能偏低比率回 passed；可證明超標照擋。代價：與第 3 條不對稱需文件化；新增 ≥ 3 句字面，W2 經 fired 訊息進推播；只有 unknown 時警示 quiet 讀不到 W3（S-B2 失效條件 4 禁接 detail）→ any 規則「其餘已評估的上限皆未違反」會算進第 2 條（S-B2 失效條件 1 重審時併審）；只監看 `sector_weight` 的規則在 same＋未達上限時由 quiet 變 skipped 句尾「缺少輸入」口徑不精確（再一例）；試算排除時出現已核可「以下上限本次缺少可用資料…」句需風控確認；`/limits` 第 2 條取代 2026-08-09 路線(a) 在 same 情境的行為，`book_limits.py` `NO_CANDIDATE_DETAIL` 註解需更新。
