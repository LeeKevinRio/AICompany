**第 2 步：停 backend 與 scheduler，確認沒有殘留。**

- 用 `dev-up.bat` 啟動的：到標題 `stock-desk backend` 與 `stock-desk scheduler` 兩個視窗各按 Ctrl+C。在 dev-up 視窗按 Ctrl+C **不會**收掉它們。
- 用主機部署手冊方式啟動的：到 API 與 scheduler 兩個視窗各按 Ctrl+C。
- 用 NSSM 或工作排程器常駐的：按 Ctrl+C 不夠，要先停用監督程式的自動重啟，再停服務。**做不到就停在這裡回報**。

```powershell
Get-CimInstance Win32_Process |
  Where-Object { $_.Name -match '^(python|pythonw|uv|uvicorn)\.exe$' -and ($_.CommandLine -like '*app.scheduler*' -or $_.CommandLine -like '*app.main:app*') } |
  Select-Object ProcessId, Name
```

**第 3 步：把三個檔複製到 repo 以外，並比對備份。** 只有在第 1 步的表格判定不是預設值時，才修改第一行的 `$DB_DIR`。

```powershell
$DB_DIR = "$REPO\apps\stock-desk\backend\data"   # dev-up default; see the table in step 1
$TS     = Get-Date -Format "yyyyMMdd-HHmmss"
$WORK   = "$HOME\stock-desk-n208\$TS"            # outside the repo; must be on a local disk
$BK     = "$WORK\backup"
$PROBE  = "$WORK\probe"
New-Item -ItemType Directory -Path $BK, $PROBE | Out-Null

foreach ($f in "stock-desk.db", "stock-desk.db-wal", "stock-desk.db-shm") {
    $src = Join-Path $DB_DIR $f
    if (Test-Path $src) { Copy-Item $src $BK; Write-Host "copied: $f" }
    else { Write-Host "not present: $f" }
}
function Test-N208Same($A, $B) {
  foreach ($f in "stock-desk.db","stock-desk.db-wal","stock-desk.db-shm") {
    $x = Join-Path $A $f; $y = Join-Path $B $f
    $r = if ((Test-Path $x) -ne (Test-Path $y)) { 'PRESENCE_DIFFERS' } elseif (-not (Test-Path $x)) { 'absent_both' } elseif ((Get-FileHash $x).Hash -eq (Get-FileHash $y).Hash) { 'SAME' } else { 'DIFFERENT' }
    "{0}: {1}" -f $f, $r
  }
}
Test-N208Same $DB_DIR $BK   # every line must be SAME or absent_both
Copy-Item "$BK\*" $PROBE
```

- **沒有看到 `copied: stock-desk.db` 就停下**，回到第 1 步的表格（§2.2）確認 `$DB_DIR`。
- `Test-N208Same` 的三行都必須是 `SAME` 或 `absent_both`；出現 `DIFFERENT` 或 `PRESENCE_DIFFERS`，代表服務沒有停乾淨，回到第 2 步。
- 複製完成後，就可以照平常方式重新啟動服務；第 4 步只讀複本，與正本無關。
