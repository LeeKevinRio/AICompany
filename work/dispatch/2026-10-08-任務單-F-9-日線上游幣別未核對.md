## tech-architect 架構評估（2026-10-12，唯讀讀碼；coordinator 轉錄）

### 結論
1. **閘門放在 `MarketDataService`，不放 `load_bars`**：估值器 `PositionValuator._resolve_price` 直接呼叫 `service.get_daily_bars`／`get_cached_bars`（`valuation.py` L451-454），不經 `load_bars`；只擋 `load_bars` 會留下最大傷害——外幣價格被當成 USD／TWD 灌進總資產，全書比率偏低（不保守）。
2. **現況「宣告幣別 ≠ 市場幣別」不會發生**：5 個 adapter 都寫死市場幣別（TWSE `twse.py` L71/L186、TPEx `tpex.py` L92/L337、FinMind `finmind.py` L70/L179、AV `alpha_vantage.py` L145/L394、yfinance `yfinance.py` L172）。F7-R14 式的幣別閘門須搭配 (ii)(iii) 代號准入規則與 (i) adapter 誠實回報上游幣別才有效。
3. **狀態**：資料層回 `DataStatus.UNAVAILABLE`、bars 清空，API 外層沿既有路徑回 `insufficient_data`；不新增 DataStatus 或 API token；但需 3～4 句新使用者面原因句（creative-lead → 風控）。
4. **需新 ADR**（暫編 ADR-0024，資料源契約；具體化 ADR-0003 約束 8、擴充 ADR-0005 決策三，不取代既有 ADR；`canonical_us_symbol` 語意不變）。
5. **第一個離線可開工 PR：F-9a**（行為不變、無新字面、不碰 UI）。**F-9b（閘門）必須早於 F-9c（yfinance 誠實回報）合併**，否則「有價格、沒單位」狀態會變多。

### 現況盤點要點
- yfinance 讀得到但未讀 `meta.currency`（`_parse_result` L335-347 只讀 timestamp／indicators）；fixture 皆合成，實際回傳待連網實證。
- `quality.check_price_bars`（含 `_check_currency`）在 app 內零呼叫者，只有 `tests/test_quality.py`。
- 快取忠實保存 currency（`cache.py` L48、L205/L225、L580/L595），但上游寫死使既有壞資料看不出異常；`market_trading_days`／`market_has_session` 不看幣別，外國代號列會汙染美股交易日行事曆。
- `MarketDataService.get_daily_bars`（`service.py` L182）、`get_cached_bars`（L244-283）、`load_bars`（`services/market.py` L147-194）皆不檢查。
- `load_bars` 消費者：`/api/bars`、`/api/signals`、`/api/advice`、alerts snapshot、portfolio limits、backtest、event study、leverage、playbook、scheduler、diagnose；繞過者：即時與 cache_only 估值器（`deps.py` L163-185）、指數 `IndexProviderBridge`。
- 代號：`canonical_us_symbol` 只剝 `.US`、允許 `[A-Z0-9.-]`，AV 轉換為 identity，`TSCO.LON` 原樣送出；台股無代號形狀檢查，且有合法字尾字母（`00679B`、`00631L`、`00632R`）。

### 設計建議
- **(i)** yfinance role 1／2 改用 `meta.currency` 原值照存（不轉大寫），缺值 role 1 回 UNAVAILABLE、不補市場預設；role 2（指數）等連網實證才合併；`fetch_chart_closes`（FX 路徑）排除並以測試釘住。屬 F-9c。
- **(ii)** 美股採**形狀白名單**：root 1–5 字母，可選單一字母類別（`.X`／`-X`）；保住 `BRK.B`／`BF.B`／`BRK-B`，擋 2 字母以上字尾（誤擋特別股、權證、單位；單一字母外國字尾擋不到，殘留）。admission 由服務層注入、在 layer 0 前執行：被拒代號不讀快取、不呼叫來源、不扣額度、不寫 attempt log；AV adapter 扣額度前再呼叫一次（縱深）。
- **(iii)** 台股以精確樣式擋「數字＋K」；不得擋 `B`／`L`／`R`／`U` 字尾（測試 `00679B`、`00631L`、`00632R`、`00635U`、`0050`、`2330` 通過）；`verified=False`，待連網實證。
- **(iv)** `_check_currency` 接上不移除：改公開 `check_currency`，`check_price_bars` 委派；預期幣別由組裝層（deps.py）從 `app.positions.models.MARKET_CURRENCY` 注入（app/data 不 import app/positions、不新增字典常值，KX-A1 續綠）；加與 `currency_matches_market` 的等價測試。
- **(v)** 單一閘門在 `MarketDataService`：入口先 admission；`_try_provider` 結果任一根不符即整條序列視為該層拒答（不寫快取、不記 `record_fetch`、照記 `record_attempt`）；所有快取讀取路徑同一檢查，整條序列 fail-closed、不刪資料。
- **字面**：既有 token 不變；`load_bars` 此情境不得接 `NO_BARS_REASON`（不實）；不得重用 `CURRENCY_MARKET_MISMATCH_NOTE`／`_CAUSE`（指持倉紀錄，不實）。需新字面 W-a（美股外國字尾被拒）、W-b（台股外幣交易單位被拒）、W-c（來源宣告幣別與市場不符）、W-d（`load_bars` 基底句或只帶 provider reason）。請風控裁示：整書成因是否沿用 `UNVALUED_POSITIONS_CAUSE`、冷卻期內改顯示 `COOLDOWN_NO_CACHE_REASON` 致幣別原因遺失能否接受。

### ADR-0024 草案要點（proposed）
- D-1 唯一閘門在 `MarketDataService`，`get_daily_bars` 與 `get_cached_bars` 所有出口皆過；D-2 整條序列 fail-closed；D-3 不符 bars 不寫快取；D-4 admission 在 layer 0 前、按市場注入，指數服務顯式「不檢查形狀、只檢查幣別」；D-5 判準單一來源 `MARKET_CURRENCY`，由組裝層注入且為必填建構參數；D-6 adapter 只回報上游宣告幣別或經 admission 保證之值，缺值不補；D-7 不新增 DataStatus 與 API token；D-8 既有壞列不自動遷移，由運維指令清理（預設 dry-run，依 ADR-0009 R-5 連帶刪 fetch_log／attempt_log）。
- 關係：具體化 ADR-0003 約束 8；擴充 ADR-0005 決策三；相容 ADR-0005 I-3 與 ADR-0009；ADR-0017 X3-F3 觸發時連帶重審。

### 實作約束（F-9b 為主）
C-1 五條讀取路徑＋即時路徑非空結果逐根等於預期幣別，否則 UNAVAILABLE、`bars=[]`（各一測試）；C-2 不得濾掉不符列回傳其餘；C-3 不符時 `cache.get` 仍 None、不 `record_fetch`、照記 `record_attempt`；C-4 被拒代號 transport 零呼叫、額度 `used` 不變、不寫 attempt log、不讀快取；C-5 app/data 不 import app/positions，KX-A1 續綠，與 `currency_matches_market` 等價測試；C-6 deps.py 三個建構點（TW、US、index）規則由測試釘住；C-7 `BRK.B`、`BF.B`、`BRK-B`、`AAPL`、`00679B`、`00631L`、`00632R`、`00635U` 通過 admission；C-8 `price_guard.py` 零 diff，F-7 前端閘門與測試不改且常綠；C-9 新字面逐字常數並標風控核可出處；C-10 `fetch_chart_closes` 行為不變。
